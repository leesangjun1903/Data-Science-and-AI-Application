## 1. Executive summary — 8문장

이 연구의 목적은 **같은 계산 블록을 반복하는 모델이, 긴 계산 전체를 역으로 추적해 학습하지 않고도 앞선 계산을 다음 단계에 유용하게 전달하도록 만드는 것**입니다.  
저자들은 이를 위해 정답에 섞인 잡음을 단계적으로 줄이는 일련의 복원 문제를 만들고, 단계 사이에서 같은 잡음과 내부 기억을 공유하는 **Looped Flows**를 제안합니다.  
추론에서는 무작위 초기 상태를 정답 방향으로 조금씩 이동시키면서 내부 기억도 갱신하므로, 계산 단계를 늘리거나 초기 잡음을 바꾸어 추가 계산과 다양한 답 생성을 수행할 수 있습니다. **[pp. 2–5, Figures 1–2, 식 (8)–(13)]** 2609.11801v1 2609.11801v1

저자 보고에 따르면 ARC의 두 후보 중 하나라도 맞히는 평가에서 TRM 대비 ARC-AGI-1은 **44.6%→58.8%**, ARC-AGI-2는 **7.8%→12.2%**로 개선되었습니다.  
Sudoku에서는 추론을 8단계에서 128단계로 늘릴 때 정확도가 **74.5%→97.9%**로 상승했고, 여러 정답이 있는 N-Queens와 Graph Coloring에서도 비교 모델보다 높은 평균 성능과 정답 다양성을 보고했습니다. **[p. 7, Table 1·Figure 3; pp. 8–9, Table 2]** 2609.11801v1 2609.11801v1 2609.11801v1

일반화와 관련해 가장 중요한 근거는, 학습 문제를 잘 맞히지만 새로운 시험 문제에는 약한 단순 흐름 모델과 달리 Looped Flows가 Sudoku 시험 성능도 높게 유지한 Figure 5입니다.  
다만 학습하지 않은 더 큰 문제로의 전이, 전혀 다른 규칙 분포로의 전이, 대규모 언어모델에서의 효과는 이 논문이 직접 입증하지 않았으며, 적은 반복 실험과 계산량이 일치하지 않는 비교도 남아 있습니다.  
따라서 제 평가는 **“작은 구조화 추론 모델의 학습과 추가 계산 활용을 개선한 유망한 방법이지만, 보편적인 알고리즘 일반화나 모든 비교 모델에 대한 우월성을 확립한 결과는 아니다”**입니다. **[pp. 7–10, Tables 1–5·Figure 5; pp. 14–17, 부록 A–E]** 2609.11801v1 2609.11801v1

### 2.1 해결하려는 문제

**[저자 설명]** 기존 루프형 모델은 내부 상태를 반복 갱신하지만, 실제 학습에서는 메모리·계산 비용 때문에 한두 단계 정도까지만 기울기를 전달하는 경우가 많습니다. 그러면 나중 단계의 손실이 앞선 단계에 “미래에 필요한 정보를 무엇으로 저장해야 하는가”를 직접 알려주기 어렵습니다. 저자들은 이러한 문제가 잘못된 답으로의 수렴이나 수렴 실패로 이어질 수 있다고 설명합니다. **[pp. 2–3, Figure 2 왼쪽, 식 (1)–(2)]** 2609.11801v1 2609.11801v1

> **용어 설명 — 루프형 모델:** 같은 신경망을 여러 번 재사용하면서 내부 기억을 갱신하는 모델입니다.  
> **시간 역전파, BPTT:** 반복 계산을 시간 순서대로 펼친 뒤, 뒤에서 발생한 오류를 앞선 계산까지 전달하는 학습 방법입니다.  
> **신용 할당:** 최종 성공·실패에 앞선 어떤 계산이 기여했는지 판단하는 문제입니다.

**[제 해석]** 이 논문의 핵심은 “기울기를 더 멀리 보내자”가 아니라, **멀리 보내지 못하더라도 인접 단계가 서로 도움을 주기 쉬운 학습 문제를 설계하자**는 접근입니다. 따라서 새로운 대형 모델 구조보다는 **반복 계산을 학습시키는 목적함수와 입력 분포의 설계**에 기여의 중심이 있습니다. **[pp. 4–5, §3.1; p. 14, 부록 A]** 2609.11801v1 2609.11801v1

## 3. 제안 방법: 수식·기호·모델 구조

### 3.1 문제 정의와 기존 학습의 한계

문제 입력을 $c$, 정답을 $x_1$, 출력 위치 수를 $L$, 범주 집합을 $V$라고 하겠습니다. 정답은 각 위치에서 하나의 범주만 1인 벡터로 표현하고, 모델은 각 범주의 확률 $\hat x$를 예측합니다. 논문이 사용하는 교차엔트로피를 성분별로 풀어 쓰면 다음과 같습니다. **[p. 3, §2]** 2609.11801v1

```math
\text{CE}(\hat x,x_1)
=
-\sum_{j=1}^{L}\sum_{v\in V}
x_1^{j,v}\log \hat x^{j,v}.
```

**기호:** $j$는 출력 위치, $v$는 범주, $x_1^{j,v}$는 정답의 해당 성분, $\hat x^{j,v}$는 예측 확률입니다.

> **용어 설명 — 원핫 표현:** 정답 범주의 위치만 1이고 나머지는 0인 표현입니다.  
> **교차엔트로피:** 정답에 높은 확률을 줄수록 작아지는 손실함수입니다.

기존 루프형 모델은 다음처럼 학습합니다. **[p. 3, 식 (1)–(2)]** 2609.11801v1

$$
z_i=f\bigl(\text{sg}(z_{i-1});c\bigr),
\qquad
\hat x_i=g(z_i),
$$

```math
\mathcal L_{\text{loop}}
=
\mathbb E_{c,x_1}
\left[
\sum_i \text{CE}(\hat x_i,x_1)
\right].
```

**기호:** $z_i$는 $i$번째 내부 상태, $f$는 공유되는 상태 갱신 신경망, $g$는 출력 변환부, $\text{sg}$는 기울기 차단, $\mathbb E$는 평균을 뜻합니다.

핵심 한계는 $\text{sg}(z_{i-1})$ 때문에 **현재 단계의 손실이 이전 상태를 만든 계산까지 직접 수정하지 못한다**는 점입니다. 다만 공유 파라미터 자체는 여러 단계의 국소 손실로 학습되므로, “이전 단계가 전혀 학습되지 않는다”는 뜻은 아닙니다. **[p. 3, 식 (2)]** 2609.11801v1

### 3.2 정답 복원을 학습하는 확률 흐름

저자들은 잡음과 정답 사이의 선형 보간을 정의합니다. **[p. 3, 식 (3)]** 2609.11801v1

$$
x_0\sim\mathcal N(0,\sigma^2\mathbf I),
\qquad
I_t=(1-t)x_0+t x_1,
\qquad 0\le t\le 1.
$$

**기호:** $x_0$는 초기 가우시안 잡음, $\sigma$는 잡음 크기, $\mathbf I$는 단위행렬, $t$는 잡음에서 정답으로 진행하는 시간, $I_t$는 학습용 보간 입력입니다.

$t=0$에서는 잡음이고, $t$가 커질수록 정답이 더 많이 드러납니다. 여기서 **학습용 $I_t$는 실제 정답으로 만들어지지만, 추론 상태 $x_t$는 모델의 예측으로 생성된다**는 차이를 기억해야 합니다. **[pp. 3–4, 식 (3), (8)–(9)]** 2609.11801v1 2609.11801v1

> **용어 설명 — 보간:** 두 값 사이를 일정 비율로 섞어 중간값을 만드는 것입니다.  
> **확률 흐름:** 개별 표본을 조금씩 이동시켜, 전체적으로 잡음 분포를 정답 분포로 바꾸는 과정입니다.

이상적인 잡음 제거 함수와 이동 속도는 다음 관계를 만족합니다. **[p. 3, 식 (4), (6)]** 2609.11801v1

```math
D_t(x;c)
=
\mathbb E[x_1\mid I_t=x,c],
```

```math
b_t(x;c)=\frac{D_t(x;c)-x}{1-t},
\qquad
\frac{dx_t}{dt}=b_t(x_t;c).
```

**기호:** $D_t$는 관측된 잡음 입력에서 예상되는 깨끗한 정답, $b_t$는 이동 속도장, $x_t$는 추론 중 상태입니다. 분모가 있는 식은 $t<1$에서 사용합니다.

**직관:** “현재 상태”와 “예상 정답”의 차이를 남은 시간으로 나눈 방향으로 이동합니다. 다만 이 관계는 이상적인 조건부 평균에 관한 것이며, 유한 데이터로 학습한 신경망이 그 함수를 정확히 복원한다는 보장은 별개입니다.

### 3.3 핵심 학습법: 상태를 가진 잡음 제거기

Looped Flows는 잡음 제거기가 정답 예측과 내부 상태 갱신을 함께 수행하도록 만듭니다. **[p. 4, 식 (9)]** 2609.11801v1

```math
\left(\hat x_{t_i},z_{t_{i+1}}\right)
=
\hat D_{t_i}
\left(I_{t_i},\text{sg}(z_{t_i});c\right),
```

```math
\mathcal L_{\text{LF}}
=
\mathbb E_{c,x_0,x_1}
\mathbb E_{(t_0,\ldots,t_k)\sim\mu}
\left[
\sum_{i=0}^{k-1}
\text{CE}(\hat x_{t_i},x_1)
\right].
```

**기호:** $\hat D_t$는 학습된 상태 보유 잡음 제거기, $z_t$는 내부 기억, $k$는 최대 학습 단계 수, $\mu$는 시간열을 뽑는 분포입니다.

이 학습의 핵심 조건은 **시간을 증가시키고, 같은 문제·정답·초기 잡음을 단계 전체에서 공유한다**는 것입니다. 각 단계는 독립적인 복원 과제가 아니라 서로 밀접하게 연결된 과제가 됩니다. **[p. 5, “Temporal alignment”]** 2609.11801v1

**[저자 가설]** 이렇게 관련된 과제를 순서대로 학습하면, 앞선 내부 상태를 재활용하는 것이 다음 복원 손실을 줄이는 데 도움이 됩니다.

**[제 해석]** 이는 내부 기억에 대한 일종의 학습 유도 장치입니다. 그러나 “미래에 유용한 상태가 반드시 학습된다”는 정리가 아니라, 절제 실험과 성능 결과로 뒷받침되는 설계 가설입니다.

실제 구현에서 $k=16$이며, 시간 추출법은 두 가지입니다. 기본 방식은 균등분포에서 뽑은 시간을 정렬하는 것이고, ARC와 N-Queens 10×10 등에서는 시작 시간을 먼저 뽑은 뒤 그 이후 구간에서 나머지 시간을 추출합니다. 따라서 **모든 실험이 완전히 동일한 시간 분포로 학습된 것은 아닙니다.** **[p. 16, Table 6·부록 E.1]** 2609.11801v1 2609.11801v1

### 3.4 실제 모델 구조

**[저자 보고]** 기반 구조는 TRM이며, 새로운 거대 구조를 만드는 대신 잡음 입력 투영층과 시간 임베딩을 추가합니다. **[p. 14, 부록 A]** 2609.11801v1

| 요소 | 구현 |
|---|---|
| 공유 계산 블록 | 2층, 내부 폭 512 |
| Sudoku | MLP-Mixer, 약 5M 파라미터 |
| 그 외 과제 | 8개 attention head를 사용하는 비인과 Transformer, 약 7M 파라미터 |
| 내부 상태 | $z=(h,\ell)$의 두 상태 |
| 출력 | $h$에서 정답 예측을 읽어냄 |
| 추가 입력 | 잡음 상태의 선형 투영과 시간 임베딩 |
| 정규화·활성화 | RMSNorm, SwiGLU; Transformer에는 회전 위치 임베딩 |
| 파라미터 증가 | 약 0.27M; Sudoku는 5.03M→5.30M |

> **용어 설명 — MLP-Mixer:** attention 대신 다층 선형·비선형 변환으로 위치와 특징 사이의 정보를 섞는 구조입니다.  
> **비인과 attention:** 앞쪽 위치만 보는 것이 아니라 모든 위치가 서로 참고할 수 있습니다.  
> **RMSNorm:** 내부 수치의 크기를 정규화하는 연산입니다.  
> **SwiGLU:** 정보가 통과하는 양을 조절하는 게이트형 활성화입니다.  
> **회전 위치 임베딩:** 벡터에 회전을 적용해 위치 정보를 표현합니다.

한 번의 잡음 제거기 호출에서는 아래 주기를 세 번 반복합니다. **[p. 14, 식 (15)]** 2609.11801v1

$$
\ell\leftarrow F_\theta(\ell+h+e_t)
\quad \text{를 }m\text{번 반복},
\qquad
h\leftarrow F_\theta(h+\ell).
$$

**기호:** $F_\theta$는 공유 신경망, $\theta$는 그 파라미터, $e_t$는 문제·잡음·시간을 인코딩한 입력입니다. $m=6$은 Sudoku, $m=4$는 나머지 과제에 사용됩니다.

학습에서는 앞의 두 주기를 기울기 없이 실행하고 마지막 주기에만 역전파합니다. 따라서 **“역전파를 사용하지 않는 모델”이 아니라, 긴 바깥쪽 반복 전체로는 역전파하지 않는 모델**입니다. **[p. 14, 부록 A]** 2609.11801v1

또한 **추론 1단계가 신경망 1층이라는 뜻은 아닙니다.** 구조에서 직접 계산하면 한 잡음 제거 단계는 공유 블록을 Sudoku에서 21번, 다른 과제에서 15번 호출합니다. 그러므로 단계 수만으로 다른 모델과 계산 효율을 비교하면 안 됩니다.

### 3.5 추론: 내부 기억과 흐름 상태의 동시 갱신

가장 단순한 추론은 다음과 같습니다. **[p. 4, 식 (8)]** 2609.11801v1

```math
\left(\hat x_{t_i},z_{t_{i+1}}\right)
=
\hat D_{t_i}(x_{t_i},z_{t_i};c),
```

```math
x_{t_{i+1}}
=
x_{t_i}
+
\Delta t_i
\frac{\hat x_{t_i}-x_{t_i}}{1-t_i},
\qquad
\Delta t_i=t_{i+1}-t_i.
```

**기호:** $\Delta t_i$는 시간 간격이며, $0=t_0<\cdots<t_n=1$인 격자를 사용합니다. $n$은 추론 단계 수입니다.

> **용어 설명 — 오일러 방법:** 현재 위치에서 계산한 이동 속도에 짧은 시간 간격을 곱해 다음 위치를 근사하는 수치해석 방법입니다.  
> **ODE:** 무작위 항 없이 상태의 변화율을 기술하는 상미분방정식입니다.

시간 격자를 더 촘촘하게 하면 흐름을 더 세밀하게 적분하는 동시에 내부 기억을 더 많이 갱신합니다. 이 두 효과가 함께 변한다는 점은, 뒤에서 일반화와 계산 확장성을 해석할 때 중요합니다. **[p. 5, “Inference-time scaling”]** 2609.11801v1

저자들은 무작위 항을 포함하는 추론도 사용합니다. 먼저 선형 가우시안 보간에서의 score는 다음과 같습니다. **[p. 5, 식 (12)]** 2609.11801v1

```math
\nabla_x\log p_t(x\mid c)
=
\frac{tD_t(x;c)-x}{\sigma^2(1-t)^2}.
```

**기호:** $p_t$는 시간 $t$의 중간 상태 분포, $\nabla_x$는 $x$에 대한 기울기입니다.

> **용어 설명 — Score:** 여기서는 시험 점수가 아니라, 로그 확률밀도가 가장 빠르게 증가하는 방향입니다.

이를 이용한 확률적 변화식은 다음과 같습니다. **[p. 5, 식 (13)]** 2609.11801v1

```math
dx_t
=
\left[
(1+\gamma t)b_t(x_t;c)-\gamma x_t
\right]dt
+
\sigma\sqrt{2\gamma(1-t)}\,dw_t.
```

**기호:** $\gamma\ge0$는 무작위성의 강도, $w_t$는 표준 브라운 운동입니다. $\gamma=0$이면 결정론적 ODE가 됩니다.

> **용어 설명 — SDE:** 무작위 흔들림을 포함하는 확률미분방정식입니다.  
> **브라운 운동:** 작은 무작위 변화가 연속적으로 누적되는 수학적 과정입니다.

실제 구현은 상태에 잡음을 추가해 약간 이전 시간으로 되돌린 뒤 다시 전진시키는 방식입니다. 한 단계의 되돌림은 다음과 같습니다. **[p. 15, 식 (18)–(19); p. 4, Algorithm 2]** 2609.11801v1

$$
a=\min\{1,\max\{0,1-\gamma\Delta t_i\}\},
\qquad s=a t_i,
$$

```math
\bar x_s
=
a x_{t_i}
+
\sqrt{(1-s)^2-(a-s)^2}\,\epsilon,
\qquad
\epsilon\sim\mathcal N(0,\sigma^2\mathbf I).
```

**기호:** $a$는 되돌림 정도, $s$는 되돌아간 시간, $\bar x_s$는 새 잡음이 더해진 상태, $\epsilon$은 새로 뽑은 잡음입니다. 이후 $\bar x_s$에서 정답을 예측하고 $t_{i+1}$까지 오일러 갱신합니다.

**중요한 구분:** ODE 추론도 초기 잡음 $x_0$를 바꾸면 서로 다른 출력을 낼 수 있습니다. 따라서 여러 답을 생성하기 위해 매 단계 잡음을 추가하는 SDE가 반드시 필요한 것은 아닙니다. **[p. 9, Tables 4–5 및 §5.3]** 2609.11801v1

### 3.6 학습 중단과 과적합 방지

#### 적응적 계산 시간

정답을 이미 잘 복원한 뒤의 단계가 과적합을 유발할 수 있어, 학습 중에는 성공 여부를 예측하는 보조 출력부를 사용합니다. **[p. 5, 식 (10)]** 2609.11801v1

```math
\hat q_i=q(z_{t_{i+1}}),
\qquad
y_i=
\mathbf 1
\left\{
\text{round}(\hat x_{t_i})=x_1
\right\},
```

```math
\mathcal L_{\text{ACT}}
=
\lambda\,
\mathbb E
\left[
\sum_{i=0}^{k-1}
\text{BCE}(\hat q_i,y_i)
\right].
```

**기호:** $\hat q_i$는 성공 예측값, $y_i$는 전체 답이 정확하면 1인 표지, $\text{round}$는 위치별 최대 확률 범주 선택, $\text{BCE}$는 이진 교차엔트로피, $\lambda$는 가중치입니다. 실험에서는 $\lambda=0.5$입니다. 2609.11801v1

> **용어 설명 — ACT:** 입력의 상태에 따라 계산량을 조절하는 장치입니다.

**다만 이 논문의 추론에서는 ACT 점수로 적분을 조기 종료하지 않습니다.** 추론 단계 수는 정해져 있고, 여러 궤적을 생성했을 때 가장 성공 가능성이 높은 답을 고르는 best-Q 선택에 이 점수를 사용합니다. **[p. 16, 부록 E.1]** 2609.11801v1

#### 의사 정답을 이용한 입력 정규화

학습 입력에 정답을 계속 섞으면 정답을 너무 쉽게 읽어내는 방식으로 과적합할 수 있습니다. 이를 줄이기 위해 일부 과제에서는 두 번째 단계부터 실제 정답 대신 이전 예측을 입력 보간에 사용합니다. **[p. 16, 식 (21)]** 2609.11801v1

```math
\widetilde I_{t_i}
=
(1-t_i)x_0
+
t_i\,\text{sg}(\hat x_{t_{i-1}}),
\qquad i\ge1.
```

**기호:** $\widetilde I_{t_i}$는 수정된 학습 입력, $\hat x_{t_{i-1}}$는 직전 단계의 예측 확률입니다.

**입력을 만드는 재료만 이전 예측으로 바뀌며, 손실의 정답은 여전히 실제 $x_1$입니다.** 처음 입력은 실제 정답으로 만들고, 이전 예측은 범주로 반올림하지 않습니다. 이 장치는 Sudoku와 ARC-AGI-2에 사용됩니다. **[p. 16, Table 6·부록 D]** 2609.11801v1

> **용어 설명 — 의사 정답, pseudotarget:** 모델이 스스로 만든 예측을 학습 과정의 일부에 활용하는 것입니다.

**[제 해석]** 이는 학습 때는 정답에 가까운 상태를 보고, 추론 때는 자기 오류가 섞인 상태를 보는 차이를 줄일 가능성이 있습니다. 다만 이 논문에는 의사 정답의 독립적인 기여를 정량적으로 분리한 표가 없어, 성능 개선 중 얼마를 설명하는지는 알 수 없습니다.

저자 정의를 수식화하면, 문제 $c$에서 가능한 정답 집합을 $\mathcal S(c)$라고 할 때 다음과 같습니다.

```math
\text{Coverage@20}(c)
=
\frac{
\left|
\{\hat x^{(1)},\ldots,\hat x^{(20)}\}
\cap \mathcal S(c)
\right|
}{
|\mathcal S(c)|
}.
```

**기호:** $\hat x^{(r)}$는 $r$번째 추론 결과이고, 집합으로 표현했으므로 중복 답은 한 번만 셉니다. 이는 p. 8의 정의를 수식으로 정리한 것입니다. 2609.11801v1

```math
\text{Coverage@20}(c)
\le
\min\left\{1,\frac{20}{|\mathcal S(c)|}\right\}.
```

따라서 정답이 훨씬 많은 문제에서 coverage가 낮아져도, 그것만으로 모델의 일반화가 악화됐다고 판단할 수 없습니다. 또한 **충돌 0.7은 오류율 0.7%가 아니며**, N-Queens의 첫 표본 정확도와 같은 척도로 비교할 수 없습니다.

**[제 해석]** 이는 학습 최대 단계인 16보다 많은 단계에서도 계산이 유용하게 쓰인다는 근거입니다. 그러나 동시에 바뀌는 것은 내부 상태 갱신 횟수와 수치 적분 간격입니다. 따라서 이 그림만으로 개선이 **더 긴 추론 알고리즘 수행** 때문인지, **더 정확한 적분** 때문인지, 또는 둘 다인지 분리할 수 없습니다.

또한 이 실험은 같은 시험 문제 집합에 더 많은 계산을 적용한 것이므로, **더 큰 문제 크기로의 일반화와 동일하지 않습니다.**

### 5.3 Figure 4 — 안정적인 오답과 불안정한 반복을 구분한다

**[저자 보고]** 두 예시에서 TRM은 각각 오답 상태에 머무르거나 진동하지만, Looped Flows는 정답에 도달합니다. 전체 분석에서는 약 65,000개 Sudoku 시험 문제를 대상으로 TRM의 실패 12.6%를 분류했고, 그 실패 사례의 90.9%를 Looped Flows가 해결했습니다. **[pp. 7–8, Figure 4]** 2609.11801v1 2609.11801v1

저자의 수렴 판정은 상대적 상태 변화량에 기반합니다.

```math
R_i
=
\frac{\|z_i-z_{i-1}\|}{\|z_{i-1}\|}.
```

**기호:** $R_i$는 직전 상태 크기에 대한 현재 변화량의 비율입니다. 마지막 여덟 단계의 잔차를 평균하고, 초기 잔차 평균의 5%보다 작은지를 이용합니다. **[pp. 7–8, §5.1]** 2609.11801v1 2609.11801v1

> **용어 설명 — 잔차:** 여기서는 연속한 두 내부 상태 사이의 차이입니다.  
> **잘못된 끌개, spurious attractor:** 반복해도 크게 변하지 않지만, 출력은 틀린 상태입니다.  
> **PCA:** 고차원 데이터를 중요한 변화 방향 몇 개로 압축해 시각화하는 방법입니다.

**[제 해석]** 이 그림의 배경 색은 **에너지값이 아니라 상태 변화 잔차**입니다. 또한 2차원 PCA 투영은 실제 고차원 동역학을 완전히 보존하지 않습니다. 그러므로 “잘못된 에너지 최소점이 제거됐음을 증명했다”거나 “모든 초기 상태에서 정답으로 수렴한다”고 읽어서는 안 됩니다.

> **용어 설명 — 보류 시험 집합:** 학습에 사용하지 않고 성능 평가를 위해 따로 둔 문제 집합입니다.  
> **과적합:** 학습 문제에는 잘 맞지만 새로운 문제에서는 성능이 떨어지는 현상입니다.  
> **FLOPs:** 계산에 사용된 부동소수점 연산의 수로, 모델 실행 비용을 비교하는 한 척도입니다.

### 6.3 공유 잡음이 만드는 지름길 가능성

저자들도 중요한 위험을 인정합니다. 두 시점의 보간 입력을 기억하면 정답을 대수적으로 추출할 수 있습니다. **[p. 14, 식 (16)]** 2609.11801v1

```math
x_1
=
\frac{(1-s)I_t-(1-t)I_s}{t-s},
\qquad 0\le s < t\le1.
```

**기호:** $I_s,I_t$는 같은 잡음과 정답으로 만든 서로 다른 시점의 입력이고, $s,t$는 그 시간입니다.

이 관계를 이용하면 실제 문제 규칙을 충분히 이해하지 않고도 학습 손실을 낮출 수 있습니다.

**[저자 논증]** 추론에서는 실제 정답이 없으므로 이 지름길만 사용하면 첫 예측을 계속 반복하게 됩니다. 실제로 추가 단계가 성능을 높인다는 점은 **모델이 오직 이 지름길에만 의존한다는 가설**을 배제합니다. **[p. 15, 식 (17)]** 2609.11801v1

**[제 해석]** 그러나 이 논증은 **부분적 의존**, 특정 문제에서의 의존, 또는 다른 지름길까지 배제하지는 못합니다. 공유 잡음의 장점과 지름길 위험을 별도로 측정하는 실험이 필요합니다.

### 6.4 이론적 보장과 실제 상태 보유 모델 사이의 간격

**[제 해석]** 논문의 확률 흐름 이론은 이상적인 $D_t(x;c)$와 $p_t$를 연결하지만, 실제 모델은 과거 계산을 담은 $z_t$에도 의존합니다. 학습에서는 정답으로 만든 보간 경로를 보고, 추론에서는 자기 예측으로 만든 경로를 봅니다. 의사 정답을 사용하면 학습 입력 분포도 원래 보간 분포에서 바뀝니다. **[pp. 3–5, 식 (6), (8)–(13); p. 16, 식 (21)]** 2609.11801v1 2609.11801v1 2609.11801v1

따라서 현재의 이론을 곧바로 **“학습된 전체 $(x_t,z_t)$ 과정이 정확한 정답 분포를 보존한다”**는 보장으로 확장해서는 안 됩니다. 부록 C의 작은 시간 간격 분석도 이상적인 예측을 대입해 SDE의 계수를 회복하는 결과이지, 학습된 전체 재귀 시스템의 수렴 정리는 아닙니다. **[p. 15, 식 (20)]** 2609.11801v1

## 9. 결론과 후속 연구 방향

### 9.1 저자들이 제시한 시사점과 계획

**[저자 결론]** 감소하는 잡음 수준과 공유 잡음으로 국소 복원 목적함수들을 연결하면, 미래 단계에 유용한 내부 상태를 학습하도록 유도할 수 있으며, 여러 추론 벤치마크에서 높은 성능을 얻을 수 있다는 것입니다. **명시적으로 제시한 후속 연구는 Looped Flows의 장점을 유지하면서 시뮬레이션 없는 학습 알고리즘을 개발하는 것**입니다. **[p. 10, §6]** 2609.11801v1

> **용어 설명 — 시뮬레이션 없는 학습:** 학습 때 긴 반복 경로를 순서대로 실행하지 않고도 필요한 학습 신호를 얻는 방식입니다. 현재 LF는 단계 사이 역전파는 차단하지만 내부 상태의 순차 실행 자체는 필요합니다.

### 9.2 제가 제안하는 후속 연구 — 일반화 중심

**첫째, 문제 크기 일반화와 계산 단계 일반화를 분리해야 합니다.**  
학습에서는 작은 그래프·짧은 경로·제한된 규칙 조합만 제공하고, 시험에서는 동일 모델에 더 큰 구조를 제공해야 합니다. 예를 들어 N-Queens 8×8 학습 후 10×10·12×12 평가를 실시하되, 입력 길이를 처리할 수 있도록 구조를 설계해야 합니다. 모델을 크기별로 다시 학습해 얻은 성능과 무학습 전이 성능은 분리해 보고하는 것이 핵심입니다. 이는 2021년 쉬운→어려운 반복 추론 연구 및 2024년 IRED가 제시한 일반화 평가 방향과 직접 연결됩니다. [arXiv](https://arxiv.org/abs/2106.04537)

**둘째, 시간 격자와 내부 반복 횟수를 독립적으로 조절해야 합니다.**  
현재는 흐름 적분 단계를 늘리면 내부 기억 갱신도 함께 늘어납니다. 흐름 격자는 고정하고 내부 반복만 늘리는 실험, 내부 기억을 고정하고 적분만 세밀하게 하는 실험을 비교하면, 성능 향상이 수치 근사의 개선인지 실제 순차 계산의 증가인지 분리할 수 있습니다. 이것이 Figure 3을 더 강한 알고리즘 일반화 증거로 발전시키는 방법입니다. **[LF p. 4, 식 (8); p. 7, Figure 3]** 2609.11801v1 2609.11801v1

**셋째, 학습–추론 상태 차이를 핵심 비교 축으로 삼아야 합니다.**  
원래 보간, 의사 정답 입력, 실제 추론에서 만든 내부 상태를 동일 조건에서 비교하고, 여기에 잡음 공유·시간 순서 조건을 교차시키는 실험이 필요합니다. FRM v3의 Fixed-Point Forcing과 비교하면 “좋은 상태를 만드는 학습 과제”와 “자신이 만든 어려운 상태에서 오류를 고치는 학습” 중 무엇이 일반화에 중요한지 검증할 수 있습니다. [arXiv](https://arxiv.org/pdf/2606.29150v3)

**넷째, 정답성과 수렴성을 따로 검증해야 합니다.**  
내부 변화가 작아졌다는 사실만으로 정답을 확정해서는 안 됩니다. 정확한 제약 검사가 가능한 Sudoku·N-Queens에서는 수렴 잔차와 실제 유효성의 관계를 측정하고, 다른 분포에서도 성공 예측값이 믿을 만한지 확인해야 합니다. 이후에야 잔차나 ACT 점수를 이용한 추론 조기 종료를 안전하게 설계할 수 있습니다. 이 필요성은 LF의 잘못된 끌개 분석과 EqR·FPRM의 수렴 중심 접근이 함께 보여주는 연구 과제입니다. 2609.11801v1 [arXiv](https://arxiv.org/abs/2605.21488)

**다섯째, 계산량을 맞춘 재현 실험을 우선해야 합니다.**  
동일한 데이터 분할, 학습 예산, 모델 선택 절차, 총 추론 FLOPs 아래에서 성능–비용 곡선을 비교해야 합니다. 특히 정답에 근접한 높은 정확도에서는 몇 개 문제의 차이가 결론을 바꿀 수 있으므로, 충분한 독립 학습 반복과 문제별 대응 평가가 필요합니다. 파라미터가 작다는 사실과 총 비용이 작다는 사실은 구분해야 합니다.

**여섯째, 언어모델 확장은 별도의 검증 단계로 다뤄야 합니다.**  
연속 흐름을 언어에 적용한 FLM/FMLM과 큰 규모의 내부 반복을 보인 Recurrent Depth 연구는 각각 확장 가능성을 뒷받침하지만, 두 성공이 LF에서 자동으로 결합되지는 않습니다. 긴 문맥, 큰 어휘, 지식 회수, 가변 길이 출력, 학습 안정성 등을 별도로 검증해야 하며, 전체 원핫 상태를 유지하는 비용도 중요한 설계 문제입니다. [arXiv](https://arxiv.org/abs/2602.16813)

### 최종 평가

**이 논문의 가장 중요한 시사점은 “작은 네트워크를 여러 번 돌리면 된다”가 아니라, “반복 계산이 일반화에 도움이 되도록 각 단계가 접하는 학습 문제와 내부 상태 분포를 설계해야 한다”는 것입니다.**

현재 증거는 **해당 벤치마크에서의 높은 시험 성능, 학습보다 긴 반복의 유용성, 다중 정답 생성**을 지지합니다. 반면 **크기·규칙·분포를 넘어서는 체계적 일반화**는 다음 단계의 연구 과제입니다. 연구의 영향력을 판단할 가장 중요한 후속 결과는 더 높은 단일 점수보다, **동일 계산 예산에서 더 낯선 문제를 얼마나 안정적으로 풀어내는가**가 될 것입니다.
