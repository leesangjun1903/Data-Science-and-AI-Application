### 2.1 무엇을 해결하려는가?

**[저자 보고]** 논문이 구분하려는 것은 다음 두 상황입니다.

- 모델이 잘못 예측했지만 데이터의 라벨은 올바른 경우.
- 모델의 예측이 타당하지만 데이터에 잘못된 라벨이 붙은 경우.

## 3. 제안 방법: 수식, 기호, 모델 구조

### 3.1 문제 설정과 핵심 가정

**[저자 보고]** 데이터셋과 라벨 오염 과정을 다음과 같이 나타낼 수 있습니다〔PDF 3–4쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

$$
X=\{(x_k,\tilde y_k)\}_{k=1}^{n},
\qquad
T_{ij}=p(\tilde y=i\mid y^\ast=j).
$$

$$
p(\tilde y=i\mid y^\ast=j,x)=T_{ij}.
$$

```math
Q_{ij}
=
p(\tilde y=i,y^\ast=j)
=
T_{ij}\pi_j,
\qquad
\pi_j=p(y^\ast=j).
```

**기호:** $n$은 표본 수, $x_k$는 $k$번째 입력, $\tilde y_k$는 관측 라벨, $y^\ast$는 참된 라벨, $i,j\in\{1,\ldots,m\}$는 클래스 번호입니다. $m$은 클래스 수, $T$는 라벨 전이행렬, $\pi_j$는 실제 클래스 $j$의 비율, $Q$는 관측 라벨과 실제 라벨의 결합분포입니다.

행렬의 방향은 중요합니다. **$Q$의 행은 관측 라벨, 열은 실제 라벨**입니다.

> **용어 풀이 — 클래스 조건부 노이즈:** 실제 클래스가 같다면, 개별 입력의 특성과 관계없이 같은 확률로 라벨이 틀린다는 가정입니다. 예를 들어 같은 개 클래스 안에서 “흐릿한 사진일수록 더 자주 오표기된다”는 현상은 이 가정으로 직접 표현되지 않습니다.  
> **용어 풀이 — 전이행렬:** 실제 클래스가 어떤 관측 라벨로 바뀌는지를 확률로 정리한 표입니다.

**[해석]** 논문의 가장 중요한 통계적 전제는 단순히 “노이즈가 존재한다”가 아니라 **노이즈가 입력 $x$에 추가로 의존하지 않는다**는 것입니다. 현실의 어려운 사례, 가려진 객체, 비꼬는 리뷰처럼 입력 난이도에 따라 오표기 확률이 달라지는 경우에는 이론을 그대로 적용할 수 없습니다.

### 3.2 모델 구조: 새로운 신경망이 아니라 외부 정제 절차

**[저자 보고]** CL 자체는 새로운 신경망 구조가 아닙니다. 기본 흐름은 다음과 같습니다〔PDF 5쪽, Figure 1〕. sminton,+12125-Article+(PDF)-26…

**오염된 데이터 → 기존 모델의 표본 외 예측 → CL의 계수·순위화·제거 → 정제된 데이터 → 최종 모델 재학습**

예측확률은 다음과 같이 표현할 수 있습니다.

```math
\hat p_{kj}
=
\hat p(\tilde y=j;x_k,\theta^{(-f(k))}).
```

**기호:** $\hat p_{kj}$는 표본 $k$의 클래스 $j$ 예측확률입니다. $f(k)$는 표본 $k$가 속한 교차검증 분할이고, $\theta^{(-f(k))}$는 그 분할을 제외하고 학습한 모델의 파라미터입니다. 이 표기는 원문의 표본 외 예측을 명시적으로 표현한 것입니다.

> **용어 풀이 — 표본 외 예측(out-of-sample prediction):** 해당 표본을 학습에 사용하지 않은 모델이 그 표본을 예측하는 방식입니다. 모델이 잘못된 라벨을 암기한 뒤 높은 확신으로 재현하는 문제를 줄이기 위한 장치입니다.  
> **용어 풀이 — 교차검증:** 데이터를 여러 부분으로 나누고, 일부를 제외하여 학습한 뒤 제외한 부분을 예측하는 절차입니다.

실험에서는 CIFAR-10에 ResNet-50, ImageNet에 ResNet-18/50을 사용합니다. Amazon Reviews에서는 fastText 표현과 다항 로지스틱 회귀를 사용합니다. 대부분의 실험은 4-fold 예측을 사용하지만, **Amazon 실험에는 5-fold가 명시**되어 있습니다〔PDF 12쪽, 15쪽, 18–19쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

**[해석]** 따라서 “모델 독립적”이라는 말은 **어떤 모델의 출력도 인터페이스로 받을 수 있다**는 뜻이지, 어떤 모델을 사용해도 같은 정제 성능이 나온다는 뜻은 아닙니다. 저자들도 모델이 예측확률을 통해 CL 성능에 영향을 준다고 명시합니다〔PDF 5쪽〕. sminton,+12125-Article+(PDF)-26…

### 3.3 클래스별 임계값

**[저자 보고: 원문 Eq. 2]**

```math
t_j
=
\frac{1}{n_j}
\sum_{k:\tilde y_k=j}
\hat p_{kj},
\qquad
n_j=\bigl|\{k:\tilde y_k=j\}\bigr|.
```

**기호:** $t_j$는 클래스 $j$의 임계값이며, $n_j$는 관측 라벨이 $j$인 표본 수입니다. $\hat p_{kj}$는 앞에서 정의한 표본 외 예측확률입니다.

즉, **“현재 $j$로 라벨링된 표본들에 모델이 평균적으로 부여하는 $j$ 확률”**을 기준으로 삼습니다. 모델이 특정 클래스에 전반적으로 높은 확률을 주면 그 클래스의 임계값도 높아집니다〔PDF 7쪽〕. sminton,+12125-Article+(PDF)-26…

> **용어 풀이 — 자기신뢰도(self-confidence):** 모델이 표본의 **현재 부착된 라벨**에 부여한 확률입니다. 모델이 가장 높게 예측한 클래스의 확률과는 다를 수 있습니다.

**[해석]** 핵심은 모든 클래스에 동일한 0.5 등의 기준을 적용하지 않는다는 점입니다. 다만 이 임계값 조정은 완전한 확률 보정을 보장하는 절차는 아닙니다.

### 3.4 Confident joint 구성

**[저자 보고: 원문 Eq. 1을 분해하여 표기]**

먼저 임계값을 통과한 클래스의 집합을 구합니다.

$$
A_k=\{j:\hat p_{kj}\ge t_j\}.
$$

$A_k$가 비어 있지 않으면, 그 안에서 예측확률이 가장 높은 클래스를 선택합니다.

```math
\hat y_k^\ast
=
\underset{j\in A_k}{\text{arg max}}\ \hat p_{kj}.
```

그다음 표본을 계수합니다.

```math
C_{ij}
=
\sum_{k=1}^{n}
\mathbf{1}
\left[
\tilde y_k=i,\;
A_k\neq\varnothing,\;
\hat y_k^\ast=j
\right].
```

**기호:** $A_k$는 표본 $k$에서 임계값을 통과한 클래스 집합, $\hat y_k^\ast$는 추정한 실제 클래스, $C_{ij}$는 관측 라벨이 $i$이고 실제 라벨이 $j$라고 판단한 표본 수입니다. $\mathbf{1}[\cdot]$는 조건이 참이면 1, 거짓이면 0인 지시함수입니다.

대각 성분 $C_{ii}$는 라벨이 맞다고 판단한 표본을, 비대각 성분 $C_{ij}$는 클래스 간 라벨 오류 후보를 나타냅니다. 아무 임계값도 넘지 못한 표본은 이 단계에서 계수하지 않습니다〔PDF 6–7쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

> **용어 풀이 — confident joint:** 확신 기준을 통과한 표본들을 클래스 쌍별로 세어 놓은 **정규화 전 계수행렬**입니다. 아직 확률분포는 아닙니다.  
> **용어 풀이 — 충돌(collision):** 한 표본이 두 개 이상 클래스의 임계값을 동시에 통과하는 경우입니다.

**재현 시 주의:** 본문 Eq. 1은 임계값을 통과한 클래스들 안에서 최대값을 선택하지만, Appendix의 Algorithm 1은 충돌 시 전체 클래스에 대한 `arg max`를 표기합니다. 두 표현은 일반적으로 항상 같지는 않으므로, 재현 연구에서는 어느 규칙을 구현했는지 명시해야 합니다〔PDF 6쪽, 35쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

### 3.5 계수행렬을 결합분포로 변환

**[저자 보고: 원문 Eq. 3의 동치 표현]**

각 행의 합이 양수일 때 다음과 같이 쓸 수 있습니다.

```math
\hat Q_{ij}
=
\frac{n_i}{n}
\frac{C_{ij}}{\sum_{\ell=1}^{m}C_{i\ell}}.
```

**기호:** $\hat Q_{ij}$는 결합확률의 추정값, $n_i/n$은 관측 클래스 $i$의 비율, $\sum_\ell C_{i\ell}$은 $C$의 $i$번째 행 합입니다.

이 식은 각 행의 비율을 관측된 클래스 비율에 맞추며, 전체 합을 1로 만듭니다〔PDF 7쪽, Eq. 3〕. sminton,+12125-Article+(PDF)-26…

결합분포를 얻으면 다음 통계량도 계산할 수 있습니다.

$$
\hat\pi_j=\sum_{i=1}^{m}\hat Q_{ij},
\qquad
\hat T_{ij}=\frac{\hat Q_{ij}}{\hat\pi_j},
\qquad
\hat\eta=1-\sum_{i=1}^{m}\hat Q_{ii}.
$$

**기호:** $\hat\pi_j$는 실제 클래스 비율의 추정값, $\hat T_{ij}$는 라벨 전이확률 추정값, $\hat\eta$는 전체 라벨 오류 비율의 추정값입니다. 마지막 식은 결합분포의 비대각 확률을 모두 더한 것과 같습니다〔PDF 8쪽의 주변분포 설명에 따른 표현〕. sminton,+12125-Article+(PDF)-26…

> **용어 풀이 — 주변분포:** 결합분포에서 한 축을 모두 더하여 얻는 분포입니다. 여기서는 관측 라벨 축을 더하면 실제 클래스 비율을 얻습니다.

**[해석]** 이 구조의 장점은 “오류가 몇 개 있을까?”와 “어떤 클래스 사이에서 오류가 발생할까?”를 같은 추정 결과에서 얻는다는 점입니다. 반대로, 특정 행에 계수된 표본이 하나도 없거나 추정 대각확률이 0이면 이후 계산에 별도 처리가 필요하며, 위 수식 자체만으로는 해결되지 않습니다.

### 3.6 순위화와 제거

**[저자 보고]** 논문은 하나의 제거 방식만 제안하지 않고 여러 변형을 비교합니다〔PDF 8–9쪽〕. sminton,+12125-Article+(PDF)-26…

| 방법 | 제거 대상과 기준 |
|---|---|
| 기본 CL: $C_{\tilde y,y^\ast}$ | confident joint의 비대각에 들어간 표본을 제거한다. |
| PBC: Prune by Class | 클래스 $i$에서 $n\sum_{j\ne i}\hat Q_{ij}$개를 제거하되, 자기신뢰도가 낮은 표본부터 선택한다. |
| PBNR: Prune by Noise Rate | 클래스 쌍 $(i,j)$마다 $n\hat Q_{ij}$개를 제거하되, $\hat p_{kj}-\hat p_{ki}$가 큰 표본부터 선택한다. |
| C+NR | PBC와 PBNR이 **동시에** 제거 대상으로 선택한 표본만 제거한다. |

여기서 PBNR의 확률 차이는 다음과 같습니다.

$$
\Delta_{k,i\rightarrow j}=\hat p_{kj}-\hat p_{ki}.
$$

**기호:** $\Delta_{k,i\rightarrow j}$는 관측 라벨이 $i$인 표본 $k$에 대해, 대안 클래스 $j$가 현재 라벨 $i$보다 얼마나 더 지지되는지를 나타냅니다.

> **용어 풀이 — 마진(margin):** 두 클래스의 점수 차이입니다. 여기서는 대안 라벨을 현재 라벨보다 얼마나 더 지지하는지 나타냅니다.  
> **용어 풀이 — 프루닝(pruning):** 선택한 표본을 훈련집합에서 제거하는 것입니다. 원논문에서는 보통 라벨만 지우는 것이 아니라 **입력과 라벨을 함께 제거**합니다.

### 3.7 정제 후 재학습

**[저자 보고]** 저자들은 제거로 인해 달라진 클래스 비율을 보정하기 위해 다음 가중치를 사용합니다〔PDF 9쪽〕. sminton,+12125-Article+(PDF)-26…

```math
w_i
=
\frac{\hat\pi_i}{\hat Q_{ii}}
=
\frac{1}{\hat T_{ii}}.
```

최종 학습은 원문의 설명을 다음과 같이 나타낼 수 있습니다.

```math
\hat\phi
=
\underset{\phi}{\text{arg min}}
\sum_{k\in\mathcal I_{\text{keep}}}
w_{\tilde y_k}
\,\ell\!\left(f_\phi(x_k),\tilde y_k\right).
```

**기호:** $w_i$는 클래스 $i$의 가중치, $\mathcal I_{\text{keep}}$는 남겨 둔 표본의 인덱스 집합, $f_\phi$는 최종 예측모델, $\phi$는 그 파라미터, $\ell$은 선택한 학습 손실함수입니다.

**[해석]** 클래스 가중치는 클래스 간 비율 변화를 보정하려는 장치입니다. 그러나 특정 클래스 안에서 어려운 표본만 선택적으로 제거되는 문제까지 자동으로 보정하지는 않습니다.

예측확률이 이미 주어졌을 때 계수·결합분포 계산은 $O(nm+m^2)$의 연산과 저장공간을 요구합니다. 이는 **교차검증 모델 학습과 예측 비용을 제외한 비용**입니다〔PDF 7쪽, 36쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

## 4. 이론적 보장은 어디까지 유효한가?

### 4.1 Theorem 1: 이상적 예측확률에서의 정확성

**[저자 보고]** 논문의 이상적 조건은 다음과 같습니다.

$$
\hat p_{ki}=p^\ast_{ki}=T_{i,y_k^\ast}.
$$

**기호:** $p^\ast_{ki}$는 표본 $k$에 대한 클래스 $i$의 이상적 예측확률입니다. 이는 해당 표본의 실제 클래스에 대응하는 라벨 전이확률입니다.

중요하게도, 여기서 “이상적”은 실제 클래스에 확률 1을 주는 것을 뜻하지 않습니다. **라벨 오염 과정의 확률을 정확히 반영한다는 뜻**입니다. 이 조건과 전이행렬의 각 대각 성분이 해당 행·열에서 최대라는 조건 아래, 저자들은 오류 표본 집합의 정확한 복원을 보입니다〔PDF 10쪽, Theorem 1〕. sminton,+12125-Article+(PDF)-26…

> **용어 풀이 — 충분조건:** 이 조건이 만족되면 결과가 성립한다는 뜻입니다. 조건을 만족하지 않는다고 반드시 실패한다는 뜻도, 현실에서 조건이 항상 만족된다는 뜻도 아닙니다.

**[해석]** 이는 좋은 출발점이지만, 같은 실제 클래스의 모든 표본이 같은 전이확률 벡터를 출력한다는 강한 이상화입니다. 일반적인 모델 확률이 어느 정도 정확하다는 주장보다 더 제한적입니다.

### 4.2 Theorem 2: 예측 오차가 있어도 임계값 판단이 유지되는 경우

**[저자 보고]** Theorem 2는 각 표본의 예측확률에 오차를 허용합니다. 핵심 직관은 다음 관계가 유지되어야 한다는 것입니다〔PDF 11쪽, Appendix A〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

$$
\hat p_{kj}=p^\ast_{kj}+\epsilon_{kj},
$$

$$
\hat p_{kj}\ge\hat t_j
\quad\Longleftrightarrow\quad
p^\ast_{kj}\ge t_j^\ast.
$$

**기호:** $\epsilon_{kj}$는 예측확률 오차, $t_j^\ast$는 이상적 확률에서 계산한 임계값, $\hat t_j$는 실제 예측확률에서 계산한 임계값입니다. 두 번째 식은 원문의 오차분포 조건 전체를 대체하는 새 정리가 아니라, **증명에서 보존하려는 임계값 비교 관계**를 드러낸 표현입니다.

> **용어 풀이 — 일관성(consistency):** 표본 수가 충분히 커질 때 추정값이 목표 값에 가까워지는 성질입니다. 유한한 데이터셋에서 항상 정확하다는 의미는 아닙니다.

### 4.3 이론을 인용할 때 반드시 붙여야 할 제한

**첫째, 유한 표본에서의 정확성 보장과 구분해야 합니다.** Appendix는 특정 평균 오차를 같게 놓는 단계에서 $n\rightarrow\infty$를 사용한다고 명시합니다. 따라서 “현실의 유한 데이터에서 모든 오류를 정확히 식별한다”는 식의 인용은 부정확합니다〔PDF 34–35쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

**둘째, 분포 추정의 정확성과 최종 모델의 일반화 성능은 다른 주장입니다.** Section 4의 정리는 주로 오류 집합과 $Q$의 추정에 관한 것입니다. 정제 후 훈련한 모델이 언제나 더 낮은 테스트 오류를 갖는다는 보편적 정리는 제시하지 않습니다〔PDF 9–11쪽〕. sminton,+12125-Article+(PDF)-26…

**셋째, Corollary 1.1의 선형변환 범위에는 수식상 주의점이 있습니다.**

**[수식 검토·해석]** 원문은 클래스별 선형변환의 계수를 실수 범위로 기술하지만, 증명에서는 부등호 방향을 그대로 유지하며 배율을 소거합니다〔PDF 10쪽, 32–33쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

이를 다음처럼 쓰면 문제가 분명해집니다.

$$
\hat p'_{kj}=a_jp^\ast_{kj}+b_j,
\qquad
t'_j=a_jt_j^\ast+b_j,
$$

```math
\hat p'_{kj}-t'_j
=
a_j(p^\ast_{kj}-t_j^\ast).
```

**기호:** $a_j$는 클래스별 배율, $b_j$는 이동값, 프라임은 변환 후 값을 뜻합니다.

$a_j<0$이면 임계값 비교 방향이 뒤집힙니다. 따라서 해당 증명을 근거로 **“임의의 실수 배율에 강건하다”**고 말해서는 안 되며, 적어도 양의 배율과 같은 추가 조건이 필요합니다. 이는 핵심 계수 알고리즘의 실험 결과를 부정하는 것이 아니라, **해당 따름정리의 문구를 그대로 일반화해서 인용할 때 발생하는 문제**입니다.

## 5. 일반화 성능은 왜 좋아질 수 있고, 왜 나빠질 수도 있는가?

### 5.1 원논문이 직접 보여준 근거

**[저자 보고]** CIFAR-10에서는 합성 오류를 제거한 뒤 원래 테스트셋에서 더 높은 정확도를 얻었습니다. Amazon Reviews에서는 추가 학습에 따라 일반 학습의 정확도가 떨어지는 반면 CL 정제 후 학습은 개선되는 양상을 보였습니다. 이는 오염된 라벨에 대한 과적합을 줄일 수 있다는 실험적 근거입니다〔PDF 12–14쪽, 19–20쪽〕. sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26… sminton,+12125-Article+(PDF)-26…

> **용어 풀이 — 과적합:** 훈련 데이터의 우연한 패턴이나 잘못된 라벨까지 맞추면서, 새로운 데이터에 대한 성능이 떨어지는 현상입니다.

**[해석]** 다만 Amazon의 50 epoch 기준 개선 폭에는 일반 학습이 이미 성능이 낮아진 시점과 비교한 효과도 포함됩니다. 예를 들어 동일한 100만 표본·10번째 표본 테스트 분할에서 일반 학습은 20 epoch에 86.3%, 50 epoch에 84.4%입니다. 따라서 CL의 90.2%를 비교할 때, 50 epoch 기준 차이 **5.8%p**와 표에 제시된 일반 학습의 가장 높은 값 대비 차이 **3.9%p**는 구분할 필요가 있습니다〔PDF 19쪽, Table 7〕. sminton,+12125-Article+(PDF)-26…

### 5.2 오류 감소와 정보 손실의 교환관계

아래는 **논문에 제시된 정리가 아니라, 정밀도·재현율의 정의에서 직접 유도한 분석**입니다.

전체 노이즈 비율을 $\eta$, 오류 탐지 재현율을 $r$, 정밀도를 $q$라고 하면 다음 관계가 성립합니다.

```math
\frac{n_{\text{keep}}}{n}
=
1-\frac{r\eta}{q},
```

```math
\eta_{\text{keep}}
=
\frac{\eta(1-r)}
{1-r\eta/q}.
```

**기호:** $n_{\text{keep}}$는 제거 후 남은 표본 수, $\eta_{\text{keep}}$는 남은 데이터의 노이즈 비율입니다. $r\eta n$은 실제로 찾아 제거한 오류 수이고, 이를 정밀도 $q$로 나누면 전체 제거 수가 됩니다. 분모가 양수인 경우를 가정합니다.

이 식은 두 가지를 동시에 보여줍니다.

**오류 제거의 이득:** 잘못된 라벨의 비율을 낮출 수 있습니다.  
**표본 제거의 비용:** 정밀도가 낮으면 올바른 학습 표본도 많이 잃습니다.

예를 들어 원논문 Table 4의 기본 CL 결과인 $\eta=0.20$, $r=0.86$, $q=0.67$을 대입하면, 반올림된 지표에 따른 계산상 전체 표본의 약 **25.7%를 제거**하고, 그중 전체 데이터의 약 **8.5%에 해당하는 올바른 표본도 제거**하며, 남은 노이즈 비율은 약 **3.8%**가 됩니다〔입력 수치: PDF 14쪽, Table 4〕. sminton,+12125-Article+(PDF)-26…

**[해석]** 노이즈는 크게 줄어도 정보 손실이 함께 발생합니다. 따라서 최종 일반화 성능은 단순히 “남은 노이즈가 적은가?”뿐 아니라 “얼마나 많은 유용한 변형과 희귀 사례를 유지했는가?”에 달려 있습니다.

### 5.3 클래스 비율 보정만으로 해결되지 않는 문제

**[해석]** 원논문의 클래스 가중치는 클래스별 표본 수 감소를 보정하려는 방식입니다. 그러나 다음 상황에서는 충분하지 않을 수 있습니다.

같은 클래스의 전형적인 사진은 남고 흐릿하거나 가려진 사진만 제거된다면, 클래스 비율이 복구되어도 그 클래스의 **다양성**은 복구되지 않습니다. 이때 정제된 데이터에서의 학습은 쉬워지지만, 실제 배포 환경의 어려운 사례에서는 성능이 낮아질 수 있습니다. 이는 원문의 가중치가 클래스별로만 정의되어 있다는 사실에서 도출되는 한계입니다〔PDF 9쪽〕. sminton,+12125-Article+(PDF)-26…

> **용어 풀이 — 선택 편향:** 특정 종류의 표본이 선택적으로 남거나 제거되어, 학습 데이터가 원래 다루려던 모집단을 제대로 대표하지 못하게 되는 현상입니다.

**핵심 판단:** CL은 일반화 성능을 개선할 수 있는 수단이지만, **오류 탐지 성능 향상 → 데이터 정제 품질 향상 → 일반화 성능 향상**의 각 연결고리는 별도로 검증해야 합니다.

> **용어 풀이 — 준지도학습:** 라벨이 있는 데이터와 라벨이 없는 데이터를 함께 사용하는 학습입니다.  
> **용어 풀이 — 특징·표현 공간:** 모델이 입력의 성질을 벡터로 나타낸 공간입니다. 비슷한 입력이 가까이 위치하도록 학습할 수 있습니다.  
> **용어 풀이 — 앙상블:** 여러 모델 또는 여러 예측을 결합하는 방식입니다.  
> **용어 풀이 — 멀티모달:** 이미지와 텍스트처럼 서로 다른 형태의 데이터를 함께 다루는 것입니다.  
> **용어 풀이 — BLEU-4:** 생성 문장과 참조 문장 사이의 최대 4단어 연속 표현 일치 등을 이용하는 평가점수입니다. 분류 정확도와 같은 단위가 아닙니다.  
> **용어 풀이 — 표준오차:** 평균 추정의 불확실성을 나타내는 값으로, 개별 실행값의 산포인 표준편차와 다릅니다.

### 9.2 방법론의 변화: 삭제, 재사용, 불확실성 개선

#### A. CL과 DivideMix: 의심 표본을 버릴 것인가, 라벨만 신뢰하지 않을 것인가?

DivideMix의 전체 손실은 다음과 같습니다〔원문 PDF 6쪽, Eq. 12〕. [arXiv](https://arxiv.org/pdf/2002.07394)

```math
\mathcal L
=
\mathcal L_{\mathcal X}
+
\lambda_u\mathcal L_{\mathcal U}
+
\lambda_r\mathcal L_{\text{reg}}.
```

**기호:** $\mathcal X$는 라벨을 활용하는 집합, $\mathcal U$는 라벨 없는 것으로 취급하는 집합입니다. $\mathcal L_{\mathcal X}$는 지도 손실, $\mathcal L_{\mathcal U}$는 준지도학습의 비지도 손실, $\mathcal L_{\text{reg}}$는 예측이 한 클래스에 몰리는 것을 막는 정규화 항이며, $\lambda_u,\lambda_r$는 가중치입니다.

**[해석]** 일반화 관점에서 이 차이는 중요합니다. 라벨은 틀려도 입력 자체는 학습에 유용할 수 있기 때문입니다. 따라서 CL의 탐지 결과를 삭제 결정에만 쓰지 않고 **라벨을 제거한 뒤 준지도학습으로 재사용하는 방식**은 원논문의 모듈성을 활용할 유력한 방향입니다.

#### B. UQ-LED: 낮은 확률과 모델의 불확실성을 구분하려는 방향

Monte Carlo Dropout의 기본 아이디어는 다음처럼 표현할 수 있습니다. 이는 UQ-LED 전체 알고리즘이 아니라 그 확률 추정 요소의 요약입니다〔UQ-LED §3–4〕. [Jair](https://www.jair.org/index.php/jair/article/download/16158/27241/50420)

```math
\bar p_{kj}
=
\frac{1}{B}
\sum_{b=1}^{B}p_{kj}^{(b)},
\qquad
H_k=-\sum_{j=1}^{m}\bar p_{kj}\log\bar p_{kj}.
```

**기호:** $B$는 확률적 예측 반복 수, $p_{kj}^{(b)}$는 $b$번째 Dropout 상태에서의 예측확률, $\bar p_{kj}$는 평균 확률, $H_k$는 평균 예측분포의 엔트로피입니다.

> **용어 풀이 — Monte Carlo Dropout:** 추론 때도 일부 신경망 연결을 무작위로 비활성화하며 여러 번 예측하여 결과의 변동성을 살피는 방법입니다.  
> **용어 풀이 — 엔트로피:** 확률이 여러 클래스에 퍼져 있을수록 커지는 불확실성 지표입니다.

**[해석]** CL의 확장에서는 “현재 라벨의 확률이 낮다”는 신호만으로 오류를 확정하기보다, 모델이 그 표본 자체를 잘 이해하지 못하는지까지 고려하는 것이 중요해지고 있습니다.

### 9.3 이 논문이 이후 연구에 미친 영향의 범위

**직접적으로 확인되는 영향**은 CL을 이용한 테스트셋 감사와 CL 자체를 수정한 UQ-LED입니다. SimiFeat·LEMoN·TRACED는 CL과 문제의식 또는 비교 기준을 공유하지만, 모두를 “CL에서 직접 파생된 알고리즘”이라고 묶는 것은 과도합니다. [NeurIPS Datasets and Benchmarks](https://datasets-benchmarks-proceedings.neurips.cc/paper/2021/file/f2217062e9a397a1dca429e7d70bc6ca-Paper-round1.pdf)

**[종합 해석]** 연구의 중심 질문은 이제 “잘못된 라벨을 찾을 수 있는가?”에서 다음으로 확장되고 있습니다.

**어떤 증거로 오류를 판단할 것인가, 얼마나 신중하게 제거할 것인가, 입력 정보는 어떻게 보존할 것인가, 그리고 정제의 효과를 어떤 독립적인 평가셋에서 확인할 것인가?**

특히 LEMoN 저자들은 희귀 개념이나 소수 집단의 올바른 사례가 오류 후보로 잘못 표시될 수 있음을 지적하며, 자동 삭제보다 전문가 검토 후보를 찾는 용도로 활용할 것을 권고합니다〔§7, Impact Statement〕. [arXiv](https://arxiv.org/html/2407.18941)

## 10. 결론과 후속 연구 방향

### 10.1 저자들이 제시한 시사점과 연구 계획

**[저자 보고]** 결론의 중심 메시지는 데이터의 라벨 불확실성을 추정하고 정제하는 일이 모델 개선과 함께 연구되어야 한다는 것입니다. 저자들은 이미지·텍스트, 신경망·비신경망에 걸친 실험을 근거로 CL의 실용성을 강조합니다〔PDF 24쪽〕. sminton,+12125-Article+(PDF)-26…

**2021년 원문에 명시된 후속 계획**은 OpenML·EgoCom·CNWL 등 추가 데이터셋 평가, Random Forest·XGBoost 같은 비신경망 모델 적용, 다른 임계값 함수 검토, 테스트셋 오류의 벤치마크 영향 분석, 의사 라벨링·커리큘럼 학습과의 결합, 반복적 방식 및 회귀 문제로의 확장입니다〔PDF 24쪽〕. sminton,+12125-Article+(PDF)-26…

> **용어 풀이 — 의사 라벨링:** 모델이 예측한 라벨을 새로운 학습 신호로 사용하는 방법입니다.  
> **용어 풀이 — 커리큘럼 학습:** 비교적 쉽거나 신뢰도가 높은 표본부터 학습하고, 점차 학습 범위를 넓히는 방식입니다.

### 10.2 추가로 제안하는 연구 방향

다음은 **원문의 계획과 구분되는 제안**입니다.

**첫 번째 우선순위는 “삭제보다 정보 보존이 더 유리한가?”를 검증하는 것입니다.** 동일한 오류 후보를 대상으로 자동 삭제, 사람 재라벨링, 라벨 제거 후 준지도학습을 비교해야 합니다. 원본 데이터 학습과 같은 수의 무작위 제거도 함께 포함하면, 오류 감소 효과와 데이터량 감소 효과를 분리할 수 있습니다.

**두 번째는 평균 성능과 함께 실패 집단을 평가하는 것입니다.** 전체 정확도 외에 클래스별 성능, 희귀 집단 성능, 어려운 입력에서의 성능, 분포가 달라진 테스트셋 성능을 보고해야 합니다. “깨끗해진 데이터”가 사실은 “쉬운 사례만 남은 데이터”인지 확인하는 것이 핵심입니다.

**세 번째는 모델 품질과 정제 알고리즘의 기여를 분리하는 것입니다.** 같은 표본 외 예측을 여러 정제 방법에 제공하는 실험과, 서로 다른 모델의 출력을 같은 CL에 제공하는 실험을 모두 수행해야 합니다. 사전학습 모델을 사용할 때에는 데이터 중복, 추가 학습 정보, 추론 비용도 함께 보고하는 편이 타당합니다.

이를 검증하기 위한 권장 실험 설계는 다음과 같습니다.

| 설계 요소 | 제안 |
|---|---|
| 평가 데이터 | 원래 테스트셋과 독립적으로 검토·수정한 테스트셋을 모두 유지하고, 가능하면 분포가 다른 외부 평가셋도 사용한다. |
| 노이즈 조건 | 클래스 조건부 합성 노이즈뿐 아니라 실제 사람 오류, 입력 의존적 오류, 희귀 클래스, 모호한 라벨을 포함한다. |
| 비교 조건 | 동일한 모델·학습 예산·데이터 증강·튜닝 예산을 사용하고, 정제용 교차검증 비용을 포함한다. |
| 반복과 통계 | 여러 학습 시드뿐 아니라 여러 노이즈 구성도 반복하고, 동일 조건을 짝지은 성능 차이와 신뢰구간을 보고한다. |
| 제거 정책 | 하나의 제거율만 보고하지 않고, 제거율에 따른 오류 탐지·남은 데이터량·최종 일반화 성능을 함께 제시한다. |
| 사람 검토 | 자동 탐지 결과는 우선 검토 후보로 취급하고, 오류 여부와 클래스 체계 문제를 구분하여 기록한다. |

### 최종 판단

**CL의 일반화 성능 향상 가능성은 분명히 실험적 근거가 있지만, 보편적 보장으로 제시할 수는 없습니다.** 원논문은 라벨 오류를 측정하고 정제하는 유용한 틀을 제공했으며, 이후 연구는 그 틀을 불확실성 추정, 특징 공간 분석, 준지도학습, 멀티모달·구조화된 주석으로 확장하고 있습니다.

연구자 관점에서 가장 중요한 후속 질문은 **“얼마나 많은 오류를 제거했는가?”가 아니라, “올바른 정보와 다양성을 얼마나 보존하면서 독립적인 평가에서 일반화 성능을 개선했는가?”**입니다.
