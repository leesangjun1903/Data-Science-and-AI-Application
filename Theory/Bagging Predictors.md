# Bagging Predictors

**핵심 판단:** 이 논문은 **학습자료의 작은 변화에 민감한 예측기를 여러 번 학습하고 결합하면 시험자료에서의 예측오차를 줄일 수 있다**는 아이디어를 제안하고 검증합니다.  
다만 **모집단에서 독립적으로 얻은 학습집합을 평균하는 이론적 결과**와 **하나의 관측자료를 부트스트랩하는 실제 배깅의 성능**은 구분해야 합니다.  
실제 배깅이 모든 모델과 데이터에서 일반화 성능을 개선한다는 보편적 보장은 제시하지 않습니다. [원문 pp.123–124, 129–131]

분석 대상은 Leo Breiman의 **「Bagging Predictors」, *Machine Learning*, 24, 123–140, 1996**입니다. 서지정보는 출판사 기록과 대조했습니다. [Springer Nature Link](https://link.springer.com/article/10.1007/BF00058655?utm_source=chatgpt.com)

## 1. Executive summary — 10문장

1. 이 논문은 학습자료가 조금 달라질 때 예측 결과가 크게 변하는 학습절차의 정확도를 개선하기 위해 **배깅(bagging)**을 제안합니다. [pp.123–124]
2. 배깅은 원래 학습집합에서 같은 크기의 자료를 복원추출하여 여러 예측기를 만들고, 회귀에서는 예측값을 평균하며 분류에서는 최다득표 클래스를 선택합니다. [p.123]
3. 저자는 분류나무 실험에서 단일나무 대비 시험 오분류율의 **상대 감소율 6–77%**를 보고합니다. [Tables 2·5, pp.125·127]
4. 회귀나무의 다섯 데이터셋에서는 시험 평균제곱오차의 **상대 감소율 21–46%**를 보고합니다. [Table 8, p.128]
5. 회귀에 대한 이론은 실제 모집단에서 얻을 수 있는 여러 학습집합의 예측을 이상적으로 평균하면 기대 제곱오차가 증가하지 않는다는 결과이며, 실제 부트스트랩 배깅의 무조건적인 성능 향상을 보장하지는 않습니다. [pp.129–130, 식 (4.1)–(4.2)]
6. 분류에서는 학습집합을 바꾸어 반복 학습했을 때 가장 자주 선택되는 클래스가 실제 최빈 정답 클래스와 일치하는지가 집계의 성공을 좌우합니다. [pp.130–131]
7. 선형회귀의 변수선택 실험은 배깅이 유리한 구간과 오히려 오차를 키우는 구간을 모두 보여주며, 최근접 이웃 실험에서는 보고된 오류율이 변하지 않았습니다. [Figure 1, p.134; Table 11, p.136]
8. 참 클래스 확률을 계산할 수 있는 waveform 실험에서는 확률 추정의 평균 절대오차가 **0.189에서 0.124로 감소**했습니다. [p.135, §6.1]
9. 저자는 배깅의 구현과 병렬화가 비교적 쉽다는 장점과 함께, 나무 앙상블에서는 단일나무의 단순한 해석가능성을 잃는다는 대가를 제시합니다. [pp.135·137]
10. **[해석]** 이러한 결과는 유망하지만, Heart 자료의 사전 복제로 인한 학습·시험 중복 위험과 방법별 가지치기 절차 차이를 고려하면 보고된 개선폭 전체를 새로운 데이터에서 그대로 기대할 수는 없습니다. [pp.125–128·137]

> **용어 풀이**
>
> - **배깅**: *bootstrap aggregating*의 줄임말로, 재표집한 자료에서 학습한 예측기들을 결합하는 방법입니다.
> - **복원추출**: 한 번 뽑은 사례를 다시 추출 대상에 넣는 방식입니다.
> - **일반화 성능**: 학습에 사용하지 않은 새로운 자료에서의 예측 성능입니다.
> - **앙상블**: 여러 모델의 결과를 결합한 예측기입니다.

## 2. 연구 배경, 해결하려는 문제, 목적과 필요성

### 2.1 해결하려는 문제: 학습자료에 따른 예측기의 불안정성

**[저자 보고]** 분류·회귀나무와 선형회귀의 변수 부분집합 선택은 학습자료가 조금 달라져도 선택하는 구조가 크게 달라질 수 있습니다. 예를 들어 나무에서는 분할에 쓰는 변수가 바뀌고, 변수선택에서는 포함되는 설명변수가 달라질 수 있습니다. 저자는 이러한 **불안정성**을 배깅의 핵심 적용 조건으로 봅니다. [p.124; p.132, §5.1]

> **용어 풀이 — 불안정성**
>
> 같은 문제를 다루더라도 학습자료를 조금 바꾸었을 때 모델의 예측이 크게 달라지는 성질입니다. 여기서 말하는 불안정성은 프로그램 오류나 학습 실패를 뜻하지 않습니다.

**[해석]** 연구의 질문은 “어떤 새로운 모델을 설계할 것인가?”보다 **“이미 사용할 수 있는 예측기의 자료 의존적 변동을 어떻게 줄일 것인가?”**에 가깝습니다. 배깅은 기존 학습절차를 반복 실행하고 출력값을 결합하는 구조이므로, 기초 학습절차를 크게 변경하지 않고 적용할 수 있습니다. [pp.123·137]

### 2.2 왜 부트스트랩이 필요한가?

**[저자 보고]** 이상적으로는 같은 모집단에서 서로 독립적인 학습집합을 여러 개 얻어 각각 모델을 학습하고 결합할 수 있습니다. 하지만 보통 실제로 보유한 학습집합은 하나뿐입니다. 배깅은 그 하나의 자료에서 부트스트랩 표본을 반복 생성하여 이 과정을 근사합니다. [p.123]

> **용어 풀이 — 부트스트랩**
>
> 관측된 자료를 반복해서 재표집하여, 자료를 다시 얻었을 때 생길 수 있는 변동을 흉내 내는 방법입니다. 원자료에 없던 새로운 정보를 만들어 내는 절차는 아닙니다.

### 2.3 연구 목적과 필요성

원문에서 확인되는 목적은 다음 세 가지입니다.

| 목적 | 연구에서 수행한 일 | 근거 |
|---|---|---|
| 예측 정확도 개선 가능성 확인 | 실제·모의 자료에서 단일 예측기와 배깅 예측기 비교 | §§2–3·5 |
| 성공·실패 조건 설명 | 회귀의 평균화 논리, 분류의 클래스 선택 조건, 안정성에 따른 교차 현상 분석 | §4; Figure 1 |
| 실용적 적용 가능성 탐색 | 부트스트랩 반복 수, 표본 크기, 클래스 확률 평균화, 병렬처리 논의 | §6 |

**[해석]** 이 연구의 필요성은 “모델 하나의 예측이 우연히 얻은 학습자료에 지나치게 좌우될 수 있다”는 문제에서 나옵니다. 다만 원문의 일반화 성능 근거는 주로 같은 자료원에서 분리한 시험집합과 정해진 생성모형의 시뮬레이션입니다. 시간, 기관, 입력 분포가 달라지는 환경에서의 성능은 검증하지 않았습니다. [pp.125–128·132–133]

## 4. 방법론, 수식, 모델 구조

### 4.1 배깅의 기본 구조

**[저자 보고]** 배깅은 다음 세 단계로 구성됩니다. [pp.123–124]

1. 원래 학습집합에서 부트스트랩 학습집합을 여러 개 생성합니다.
2. 각 학습집합에 동일한 학습절차를 적용합니다.
3. 회귀는 평균, 분류는 최다득표로 예측을 결합합니다.

이는 **여러 기초 예측기를 병렬로 배치하고 마지막에 출력을 결합하는 구조**입니다. 논문의 실험에서는 나무와 선형 변수선택을 사용합니다. 각 부트스트랩 모델의 학습은 다른 모델과 통신할 필요가 없다고 설명합니다. [p.135, §6.2]

### 4.2 기호와 부트스트랩 표본

학습집합을 다음과 같이 나타냅니다.

$$
\mathcal L=\{(y_i,x_i)\}_{i=1}^{N}.
$$

| 기호 | 의미 |
|---|---|
| $\mathcal L$ | 원래 학습집합 |
| $N$ | 학습 사례 수 |
| $x_i$ | $i$번째 사례의 입력 특성 |
| $y_i$ | $i$번째 사례의 정답 또는 수치 반응 |
| $\varphi(x,\mathcal L)$ | $\mathcal L$로 학습한 모델이 새 입력 $x$에 내놓는 예측 |
| $\mathcal L^{*(b)}$ | $b$번째 부트스트랩 학습집합 |
| $B$ | 부트스트랩 모델 수 |
| $J$ | 분류 문제의 클래스 수 |

각 $\mathcal L^{*(b)}$는 $\mathcal L$에서 **복원추출로 $N$번 뽑아** 만듭니다. 따라서 총 추출 수는 $N$이지만, 어떤 사례는 여러 번 들어가고 어떤 사례는 빠집니다. [p.123]

**[직접 유도]** 특정 사례가 한 번도 선택되지 않을 확률은 다음과 같습니다.

```math
\text{Pr}\{\text{특정 사례가 제외됨}\}
=
\left(1-\frac1N\right)^N
\longrightarrow e^{-1}\approx0.368.
```

서로 다른 원래 사례의 수를 $U$라고 하면,

```math
\mathbb E[U]
=
N\left[1-\left(1-\frac1N\right)^N\right]
\approx0.632N.
```

여기서 $\mathbb E$는 기댓값, $U$는 한 부트스트랩 표본 안에 포함된 **서로 다른 사례의 수**, $e$는 자연상수입니다. 원문은 약 37%가 빠진다는 사실과 약 0.632의 포함확률을 설명합니다. [p.136, §§6.3–6.4]

> **용어 풀이 — 기댓값**
>
> 같은 무작위 과정을 여러 번 반복했을 때의 평균입니다. 한 번 만든 부트스트랩 표본에 반드시 정확히 $0.632N$개의 서로 다른 사례가 들어간다는 뜻은 아닙니다.

### 4.3 회귀: 예측값의 평균

유한한 $B$개 모델을 명시하도록 원문의 표기를 정리하면 다음과 같습니다.

```math
\widehat\varphi_{\text{bag},B}(x)
=
\frac1B\sum_{b=1}^{B}
\varphi(x,\mathcal L^{*(b)}).
```

- $\widehat\varphi_{\text{bag},B}(x)$: 최종 배깅 예측값입니다.
- $\varphi(x,\mathcal L^{*(b)})$: $b$번째 부트스트랩 모델의 예측값입니다.
- $B$: 평균에 사용한 모델의 수입니다.

**[저자 보고]** 회귀나무 실험에서는 $B=25$를 사용했습니다. 선형 변수선택 실험에서는 별도로 $B=50$을 사용했습니다. [p.128; p.133]

### 4.4 분류: 최다득표 클래스 선택

```math
\widehat c_{\text{bag},B}(x)
=
\underset{j\in\{1,\ldots,J\}}{\text{arg max}}
\sum_{b=1}^{B}
\mathbf1\{\varphi(x,\mathcal L^{*(b)})=j\}.
```

- $\widehat c_{\text{bag},B}(x)$: 최종 예측 클래스입니다.
- $\mathbf1\{\cdot\}$: 조건이 참이면 1, 거짓이면 0인 지시함수입니다.
- $\text{arg max}$: 값이 가장 커지는 클래스 번호를 선택합니다.
- $j$: 후보 클래스 번호입니다.

**[저자 보고]** 분류나무 실험에서 동률이면 클래스 라벨이 가장 작은 클래스를 선택합니다. [p.125]

> **용어 풀이 — 최다득표**
>
> 가장 많은 표를 얻은 클래스를 선택하는 방식입니다. 클래스가 셋 이상이면 선택된 클래스가 전체 표의 절반을 넘지 않아도 됩니다.

### 4.5 회귀의 이론: 이상적 평균화가 작동하는 이유

**[저자 보고]** 실제 모집단 분포를 $P$라고 하고, 그 분포에서 얻을 수 있는 여러 학습집합에 대해 평균한 예측기를 정의합니다. [p.129]

```math
\varphi_A(x)
=
\mathbb E_{\mathcal L}\big[\varphi(x,\mathcal L)\big].
```

여기서 $\mathbb E_{\mathcal L}$은 **학습집합 자체가 달라지는 무작위성에 대한 평균**이며, $A$는 집계된 예측기를 뜻합니다.

고정된 입력 $x$와 출력값 $y$에 대해 원문 식 (4.1)은 다음과 같습니다.

```math
\mathbb E_{\mathcal L}
\left[(y-\varphi(x,\mathcal L))^2\right]
=
y^2
-2y\,\mathbb E_{\mathcal L}[\varphi(x,\mathcal L)]
+\mathbb E_{\mathcal L}[\varphi(x,\mathcal L)^2].
```

제곱의 기댓값이 기댓값의 제곱보다 작지 않다는 성질을 적용하면,

$$
\mathbb E_{\mathcal L}
\left[(y-\varphi(x,\mathcal L))^2\right]
\geq
(y-\varphi_A(x))^2.
$$

새 입력·출력의 분포에 대해서도 평균하면, **이상적 집계기의 MSE는 단일 예측기의 MSE를 가능한 학습집합 전체에 대해 평균한 값보다 크지 않습니다.** [p.129]

**[직접 유도]** 위 식을 분산으로 정리하면 이유가 더 분명해집니다.

```math
\mathbb E_{\mathcal L}
\left[(y-\varphi(x,\mathcal L))^2\right]
=
(y-\varphi_A(x))^2
+
\text{Var}_{\mathcal L}[\varphi(x,\mathcal L)].
```

$\text{Var}_{\mathcal L}$은 학습자료를 바꾸었을 때 예측값이 얼마나 변하는지를 나타내는 분산입니다. 이 식은 원문 식 (4.1)을 직접 정리한 것이며, 원문에 별도로 인쇄된 식은 아닙니다.

> **용어 풀이 — 분산**
>
> 값들이 평균 주위에서 얼마나 퍼져 있는지를 나타냅니다. 여기서는 학습자료가 달라지면서 생기는 예측값의 흔들림입니다.

**[해석]** 이 결과의 정확한 의미는 **기대 MSE의 비증가**입니다. 예측값이 전혀 흔들리지 않으면 분산 항은 0이므로 엄격한 개선은 없습니다. 또한 모든 개별 학습집합에서 얻은 단일 모델보다 집계기가 좋다는 뜻도 아닙니다.

### 4.6 실제 배깅에는 왜 같은 보장이 바로 적용되지 않는가?

**[저자 보고]** 실제 배깅은 미지의 모집단 $P$ 대신, 관측된 각 사례에 확률 $1/N$을 부여한 **경험분포 $P_{\mathcal L}$**를 사용합니다. [pp.129–130]

무한히 많은 부트스트랩을 평균하는 한계를 명시하면,

```math
\varphi_{\text{bag},\infty}(x\mid\mathcal L)
=
\mathbb E_{\mathcal L^*\sim P_{\mathcal L}^{N}}
[\varphi(x,\mathcal L^*)]
=
\varphi_A(x,P_{\mathcal L}).
```

- $P_{\mathcal L}$: 원래 관측자료에 같은 확률을 부여한 경험분포입니다.
- $P_{\mathcal L}^{N}$: 그 분포에서 독립적으로 $N$번 추출한 학습집합의 분포입니다.
- $\infty$: 부트스트랩 반복 수를 무한히 늘린 평균입니다.
- $\mid\mathcal L$: 원래 학습자료를 고정한 조건에서 계산한다는 뜻입니다.

> **용어 풀이 — 경험분포**
>
> 실제 모집단 전체 대신 현재 관측한 사례들에 확률을 배정하여 만든 분포입니다.

**[해석]** 모델 수를 늘리면 주어진 자료에서의 평균을 더 정밀하게 계산할 수 있지만, 그 자료가 모집단을 완벽하게 대표하게 되는 것은 아닙니다. 따라서 **배깅이 편향에는 전혀 영향을 주지 않고 분산만 줄인다**거나 **$B$를 충분히 키우면 단일 모델보다 반드시 좋아진다**는 주장은 원문이 보장하는 범위를 벗어납니다. [pp.129–130]

### 4.7 분류의 이론: 올바른 클래스 선택 경향

원문은 다음 두 확률을 구분합니다. [p.130]

```math
Q(j\mid x)
=
\text{Pr}_{\mathcal L}\{\varphi(x,\mathcal L)=j\},
\qquad
P(j\mid x)
=
\text{Pr}\{Y=j\mid X=x\}.
```

- $Q(j\mid x)$: 학습자료를 새로 얻어 반복 학습할 때 모델이 클래스 $j$를 예측하는 빈도입니다.
- $P(j\mid x)$: 실제 데이터 생성 과정에서 입력 $x$의 정답이 $j$일 확률입니다.
- $X,Y$: 무작위 입력과 정답입니다.

단일 학습절차의 조건부 정답 확률은,

$$
\sum_{j=1}^{J}Q(j\mid x)P(j\mid x).
$$

이상적 집계기는 $Q(j\mid x)$가 가장 큰 클래스를 선택합니다. 원문은 다음 조건을 **order-correct**라고 부릅니다.

```math
\underset{j}{\text{arg max}}\;Q(j\mid x)
=
\underset{j}{\text{arg max}}\;P(j\mid x).
```

이 조건이 성립하는 입력에서는 이상적 집계기의 정답 확률이 $\max_jP(j\mid x)$가 됩니다. [pp.130–131]

> **용어 풀이**
>
> - **Order-correct**: 모델이 가장 자주 선택하는 클래스가 실제로 가장 가능성이 높은 정답 클래스와 일치한다는 뜻입니다.
> - **베이즈 예측기**: 실제 정답 확률을 알고 있다고 할 때 가장 가능성이 큰 클래스를 고르는 예측기입니다. 해당 분포에서 가능한 최소 분류오류를 달성합니다.

**[저자 보고: 예시]** $P(1\mid x)=0.9$, $P(2\mid x)=0.1$이고, 모델의 선택 빈도가 $Q(1\mid x)=0.6$, $Q(2\mid x)=0.4$이면 단일 절차의 정답 확률은 다음과 같습니다.

$$
0.6\times0.9+0.4\times0.1=0.58.
$$

이상적 투표는 클래스 1을 선택하므로 정답 확률은 $0.90$입니다. [p.131]

**[해석]** 이 예시는 올바른 선택 경향을 집계가 강화하는 이유를 보여줍니다. 반대로 잘못된 클래스를 더 자주 선택하는 입력에서는 집계가 오분류를 강화할 수 있습니다. 원문은 실제 부트스트랩이 언제 이 조건을 만족하는지 사전에 판정하는 방법을 제공하지 않습니다.

> - **교차검증**: 자료의 일부를 번갈아 검증에 사용하여 모델 설정을 선택하거나 성능을 추정하는 절차입니다.

> **용어 풀이 — OOB**
>
> *Out-of-bag*의 약자로, 특정 부트스트랩 표본에 포함되지 않은 사례를 뜻합니다. 원래 학습집합 전체를 평가에 쓰는 것과는 구별됩니다.

### 4.9 선형 변수선택 실험의 구조

원문 생성모형은 다음과 같습니다. [pp.132–133]

$$
y=\sum_{m=1}^{M}\beta_mx_m+\epsilon,
\qquad
\epsilon\sim\mathcal N(0,1),
$$

$$
M=30,\qquad N=60,\qquad
\mathbb E[X_iX_j]=\rho^{|i-j|},
\qquad
\rho\sim\text{Uniform}[0,1].
$$

- $M$: 후보 설명변수 수입니다.
- $\beta_m$: $m$번째 변수의 참 계수입니다.
- $\epsilon$: 평균 0, 분산 1의 정규잡음입니다.
- $\rho$: 변수 간 상관 정도를 조절하며 매 반복 새로 선택합니다.
- 입력 변수들은 평균 0의 다변량 정규분포에서 생성됩니다.

계수는 중심이 $k=5,15,25$인 세 군집으로 구성하며, 한 군집의 모양은 다음과 같습니다.

```math
\beta_m
=
c\left[(h-|m-k|)^+\right]^2,
\qquad
z^+=\max(z,0).
```

$h\in\{1,3,5\}$는 군집의 폭, $c$는 정규화 상수입니다. 세 설정의 비영 계수 수는 각각 **3, 15, 27개**이고, 원문은 $R^2$가 약 $0.75$가 되도록 정규화했다고 설명합니다. [pp.132–133]

> **용어 풀이**
>
> - **비영 계수**: 값이 0이 아닌 계수입니다. 이 생성모형에서는 결과에 실제로 영향을 주는 변수를 뜻합니다.
> - **상관**: 두 변수가 함께 움직이는 정도입니다.
> - **$R^2$**: 결과의 변동을 신호가 얼마나 설명하는지를 나타내는 척도입니다. 원문은 출력과 전체 최소제곱 예측기 간 상관계수의 제곱으로 설명합니다.

**[저자 보고]** 전진 변수선택으로 변수 수가 1개부터 30개인 예측기들을 만들고, 각 부트스트랩에서도 **변수선택을 다시 수행**한 후 같은 변수 수의 예측값을 평균합니다. [pp.132–133]

> **용어 풀이 — 전진 변수선택**
>
> 아직 포함하지 않은 변수 중 추가했을 때 훈련 오차가 가장 많이 줄어드는 변수를 하나씩 넣는 절차입니다.

> **용어 풀이**
>
> - **표준오차(SE)**: 추정한 평균값이 얼마나 불확실한지를 나타내는 척도입니다. 개별 사례의 오차나 자료 자체의 표준편차와는 다릅니다.
> - **%p**: 두 퍼센트 값의 차이입니다. 예를 들어 29.1%에서 19.3%로 감소하면 9.8%p 감소입니다.

상대 감소율은 다음 의미입니다.

```math
\text{상대 오류 감소율}
=
\frac{\bar e_s-\bar e_B}{\bar e_s}\times100\%.
```

$\bar e_s$는 단일 모델의 평균오류, $\bar e_B$는 배깅의 평균오류입니다.

**Waveform에서의 중요한 구분:** 저자는 알려진 최소 오류율을 14%로 제시합니다. [p.126]

- 전체 오류의 상대 감소는 약 34%입니다.
- **[직접 유도]** 최소 오류를 초과한 부분의 감소는 다음과 같이 약 65%입니다.

$$
\frac{29.1-19.3}{29.1-14.0}\approx0.649.
$$

따라서 원문의 “초과오류가 약 3분의 2 감소했다”는 설명과 “오류율이 34% 감소했다”는 설명은 서로 다른 분모를 사용합니다.

**Diabetes의 제한:** 개선이 작은 이유가 최소 가능한 오류율에 가까워졌기 때문이라는 설명은 저자도 **추측**이라고 명시합니다. 비교에 인용한 22.3%는 다른 연구의 12-fold 교차검증 결과이므로, 배깅의 23.9%와 직접 비교해 최적 한계를 확정할 수 없습니다. [p.126]

**Statlog 순위의 내부 불일치:** 저자는 네 데이터에서의 순위를 2위·1위·2위·1위로 서술하면서 평균 순위는 1.8이라고 보고합니다. 네 값의 단순 산술평균은 1.5입니다. 집계 방식의 추가 설명이 없어, **보고된 1.8을 임의로 수정하지 않고 설명되지 않은 불일치로 남겨야 합니다.** [p.127]

### 5.4 클래스 확률 평균화

확률 추정치를 평균하는 방식은 다음과 같습니다.

```math
\widehat p_{\text{bag}}(j\mid x)
=
\frac1B\sum_{b=1}^{B}\widehat p_b(j\mid x).
```

$\widehat p_b(j\mid x)$는 $b$번째 모델이 추정한 클래스 확률이고, $\widehat p_{\text{bag}}$은 그 평균입니다.

**[저자 보고]** 모든 분류 예제에서 확률 평균 후 최댓값을 선택하는 방식의 오분류율은 투표 방식과 사실상 동일했습니다. 별도의 상세 수치표는 제공하지 않습니다. [p.135, §6.1]

참 확률을 계산할 수 있는 waveform에서는 학습 300개, 시험 300개, 부트스트랩 25회, 전체 50회 반복으로 다음 결과를 얻었습니다.

| 지표 | 단일나무 | 배깅 |
|---|---:|---:|
| 클래스 확률의 평균 절대오차 | 0.189 | 0.124 |

저자는 34% 감소로 보고합니다. [p.135]

**[비교 불가]** 이 값은 분류 오류율이 아닙니다. 또한 확률오차 개선을 보였다는 사실만으로 모든 상황에서 확률의 보정 상태가 개선되었다고 결론 내릴 수는 없습니다.

> **용어 풀이 — 확률 보정**
>
> 모델이 70%라고 예측한 사건들이 실제로도 약 70% 발생하는지처럼, 예측 확률과 실제 발생 빈도가 맞는지를 뜻합니다.

|---:|---:|

단일나무의 오류율은 29.1%입니다. **이 실험에서는** 적은 반복으로 상당한 개선을 얻었고, 25개 이후의 추가 개선은 작았습니다. 저자도 25개나 50개가 모든 문제에 필요하거나 충분하다는 뜻은 아니라고 밝힙니다. [p.135]

> **용어 풀이**
>
> - **예측구간**: 새 관측값이 들어갈 것으로 예상하는 범위입니다.
> - **포함확률**: 새로운 정답이 그 구간 안에 들어가는 확률입니다.
> - **교환가능성**: 관측치의 순서를 바꾸어도 공동 확률구조가 달라지지 않는 성질입니다.
> - **Ridge 회귀**: 회귀계수가 지나치게 커지지 않도록 계수 제곱합에 벌점을 주는 방법입니다.
> - **Ridgeless 회귀**: ridge 벌점을 0으로 보내 얻는 해이며, 해가 여러 개이면 최소노름 해와 연결됩니다.
> - **고차원 점근 분석**: 표본 수와 변수 수가 함께 커지고 그 비율이 일정해지는 상황을 분석하는 방식입니다.
> - **완전 앙상블**: 정해진 크기의 가능한 부분표본 전체에서 학습한 결과를 평균하는 이론적 구성입니다.
> - **GCV**: 일반화 교차검증으로, 특정 회귀구조에서 자료를 반복 분할하지 않고 예측위험을 추정하는 방법입니다.
> - **일치성**: 표본이 증가할수록 추정값이 목표값에 가까워지는 성질입니다.
> - **FI**: *feature instability*로, 특성 하나를 제거했을 때 모델 출력이 변하는 정도입니다.

### 8.2 후속 연구가 추가한 중요한 수식

#### A. 배깅의 안정성을 직접 수량화하기

Soloff 등의 무한 배깅 결과를 기호가 겹치지 않도록 정리하면, 다음 안정성을 다룹니다.

```math
\frac1n\sum_{i=1}^{n}
\mathbf1\left\{
\left|\widehat f_\infty(x)
-\widehat f_\infty^{(-i)}(x)\right| > \varepsilon
\right\}
\leq\delta.
```

- $n$: 학습 표본 수입니다.
- $\widehat f_\infty$: 무한 배깅 예측기입니다.
- $\widehat f_\infty^{(-i)}$: 사례 $i$를 제거한 자료에서의 대응 예측기입니다.
- $\varepsilon$: 허용하는 예측 변화량입니다.
- $\delta$: 그 변화량을 초과해도 되는 사례의 비율입니다.

출력이 $[0,1]$에 있고 논문의 재표집·삭제 일관성 조건을 만족할 때, 충분조건을 다음처럼 쓸 수 있습니다.

$$
\delta\varepsilon^2
\geq
\frac{1}{4(n-1)}
\frac{\pi}{1-\pi}.
$$

$\pi\in(0,1)$는 특정 사례가 한 bag에 포함될 확률입니다. 균일한 비복원 부분표집에서 bag 크기가 $m$이면 $\pi=m/n$입니다. 유한한 $B$에는 추가적인 무작위 평균화 오차가 붙습니다. [Soloff et al., Theorems 8–9, p.10] [jmlr.org](https://jmlr.org/papers/volume25/23-0536/23-0536.pdf?utm_source=chatgpt.com)

**[해석]** 이 식은 “자료 하나를 제거했을 때 얼마나 흔들리는가?”를 보장합니다. 그 자체로 정답과의 거리가 작다는 뜻은 아닙니다.

#### B. 부분표집과 ridge 정규화의 관계

Du 등의 핵심 결과는 다음 등식입니다.

```math
\min_{\phi_s\geq\phi}R_\infty^0(\phi,\phi_s)
=
\min_{\lambda\geq0}R_\infty^\lambda(\phi,\phi).
```

- $\phi=\lim p/n$: 변수 수 $p$와 전체 표본 수 $n$의 극한 비율입니다.
- $\phi_s=\lim p/k$: 변수 수와 부분표본 크기 $k$의 극한 비율입니다.
- $\lambda$: ridge 벌점 강도입니다.
- $R_\infty^\lambda$: 완전 앙상블의 점근적 제곱 예측위험입니다.
- 윗첨자 $0$: ridge 벌점이 없는 경우입니다.

해당 선형모형과 극한에서는 **부분표본 크기를 최적화한 ridgeless 앙상블이 최적 ridge와 같은 위험을 달성**합니다. [Du et al., Theorem 2.3, p.4] [proceedings.mlr.press](https://proceedings.mlr.press/v202/du23d/du23d.pdf?utm_source=chatgpt.com)

> **용어 풀이 — 암묵적 정규화**
>
> 명시적인 벌점 항을 추가하지 않아도 학습 방식 자체가 모델의 과도한 적합을 억제하는 효과입니다.

**[해석]** 이는 두 방법이 모든 유한자료에서 같은 예측값을 낸다는 뜻이 아닙니다. 또한 이 선형모형의 결과를 임의의 신경망에 적용할 수 있다는 주장도 아닙니다.

### 9.1 저자가 제시한 결론과 시사점

**[저자 보고]** 배깅은 기존 학습절차 앞에 재표집 과정을, 뒤에 집계 과정을 추가하는 비교적 간단한 방법입니다. 특히 불안정한 예측기의 정확도를 개선할 수 있고, 각 모델을 독립적으로 학습하므로 병렬처리에 적합합니다. 나무의 경우 정확도 향상과 함께 단일나무의 해석가능성을 잃는 대가가 있습니다. [pp.135·137]

학술적 기여는 **학습자료의 변동에 대한 예측기의 반응을 개선 대상으로 삼았다는 점**, 그리고 회귀와 분류에서 집계의 작동 조건을 구분했다는 점에 있습니다. 실용적으로는 기존 학습절차를 재사용하면서 성능을 개선할 수 있는 구조를 제공합니다. [pp.123–124·129–131·137]

**후속 연구 계획에 관해서는 정확한 구분이 필요합니다.** 원문은 확률 평균화, 반복 수, 부트스트랩 크기, 신경망에 대한 적용 가능성을 논의하지만, 구체적인 일정이나 체계적인 후속 연구 계획 목록을 제시하지는 않습니다. [§6, pp.133–137]

### 9.4 추가 후속 연구 방향

**[후속 제안]**

1. **안정성과 오류를 동시에 측정합니다.** 예측이 덜 흔들리는 현상과 실제 정답에 더 가까워지는 현상이 언제 함께 나타나는지 확인해야 합니다.
2. **유한 모델 수의 성능을 연구합니다.** 무한·완전 앙상블 이론이 실제로 사용할 수 있는 작은 $B$에서 얼마나 잘 근사되는지 검증할 필요가 있습니다.
3. **재표집 크기와 모델 복잡도를 함께 선택합니다.** 나무 깊이, 변수 수, 부분표본 크기는 각각 다른 방식으로 안정성과 정확도에 영향을 줄 수 있으므로 분리해 평가합니다.
4. **점예측과 불확실성 평가를 별도로 보고합니다.** 오류가 낮아지는 것, 확률이 잘 맞는 것, 예측구간이 정답을 포함하는 것은 각각 다른 검증 목표입니다.
5. **독립 자료에서 재검증합니다.** 원문에서 다루지 않은 시간·기관·분포 변화에 대해서는 별도의 시험이 필요합니다.

이 논문에서 가장 유용하게 가져올 연구 원칙은 **“불안정한 학습절차의 여러 가능한 결과를 평균해 더 나은 예측기를 만들 수 있다”**는 것입니다. 실제 적용에서는 **어떤 변동을 평균했는지, 어떤 비교 절차를 사용했는지, 새로운 자료에서 무엇이 개선되었는지**를 함께 확인해야 합니다.
