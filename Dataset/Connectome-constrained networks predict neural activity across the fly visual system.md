## 2. 연구 목적과 필요성: 무엇을 해결하려는가?

### 2.1 연결지도는 회로의 ‘배선’이지, 작동 방식의 완전한 명세가 아니다

**[저자 보고]** 전자현미경으로 뉴런 사이의 연결을 측정할 수 있어도, 각 뉴런의 반응 속도, 휴지막전위, 개별 시냅스의 실제 강도 등을 같은 회로 전체에서 포괄적으로 측정하기는 어렵습니다. 반대로 과제 수행만을 목표로 학습한 일반 인공신경망은 실제 뇌와 전혀 다른 연결구조로도 같은 과제를 해결할 수 있습니다〔p. 1〕. s41586-024-07939-3

**[해석]** 논문이 해결하려는 것은 다음과 같은 역문제입니다.

> “이 회로가 어떻게 연결되어 있고 무엇을 계산해야 하는지는 대략 안다; 그렇다면 아직 측정하지 못한 뉴런의 동적 특성과 자극 반응을 추론할 수 있는가?”

핵심은 연결정보와 과제정보를 **서로 보완적인 제약**으로 사용하는 것입니다. 연결정보는 가능한 회로를 제한하고, 과제정보는 그 회로에서 가능한 작동 방식 중 일부를 배제합니다. 다만 두 제약을 결합해도 해답이 반드시 하나가 되지는 않으며, Fig. 3은 실제로 여러 해법이 남음을 보여줍니다. s41586-024-07939-3

> **용어 풀이**  
> **역문제(inverse problem)**: 관측된 구조나 결과에서 그것을 만들어 낸 내부 파라미터를 추정하는 문제.  
> **식별가능성(identifiability)**: 서로 다른 파라미터가 관측자료를 똑같이 설명하지 않고, 자료를 통해 구별될 수 있는 성질.

### 2.2 왜 초파리 운동 시각 회로인가?

**[저자 보고]** 이 회로는 연결구조 자료와 세포별 기능 연구가 모두 풍부하고, 운동 검출은 공간적으로 떨어진 위치의 신호를 시간에 걸쳐 비교해야 하므로 회로의 시간적 동역학을 시험하기에 적합합니다〔pp. 2–3〕. s41586-024-07939-3 s41586-024-07939-3

**[해석]** 이는 어려운 문제를 무작정 전체 뇌에서 시작하기보다, **연결정보가 비교적 잘 알려져 있고 독립적인 기능 검증자료도 있는 회로에서 방법론을 검증한 선택**입니다. 따라서 성공의 의미는 크지만, 이를 연결자료가 불완전하고 수행 과제도 불명확한 다른 뇌 영역에 곧바로 일반화할 수는 없습니다.

## 4. 제안 방법과 모델 구조: 수식 중심 설명

### 4.1 먼저 구분해야 할 세 가지 범위

**[저자 보고]** 모델의 기반은 초파리 시각계 전체를 한 개체에서 완전히 재구성한 원본 그래프가 아니라, 여러 국소 재구성 자료를 합치고 공간적으로 반복 배치한 **운동 경로의 부분적·합의적 커넥톰**입니다. 중앙 시야를 721개 육각 격자 열로 모델링합니다〔pp. 2–3〕. s41586-024-07939-3 s41586-024-07939-3

또한 “신경활동 자료 없이 학습했다”는 말은 “전자현미경 연결정보 이외의 생물학적 지식을 전혀 사용하지 않았다”는 뜻이 아닙니다. 연결의 흥분성·억제성 부호에는 신경전달물질 및 수용체 발현 자료가 사용되었고, 일부 유형은 가능한 전달물질 특성을 추정했습니다〔Methods p. 10〕. s41586-024-07939-3

별도 보충자료에는 수작업으로 구성한 회로 요소, Tm9→T5 연결 필터의 해부학 문헌 기반 보정 등도 명시되어 있습니다〔Supplementary Note 2, 별도 PDF p. 12〕. 따라서 **완전 자동화된 ‘배선도 입력→기능 출력’ 절차로 묘사하는 것은 부정확합니다.** [Springer Nature](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-024-07939-3/MediaObjects/41586_2024_7939_MOESM1_ESM.pdf)

> **용어 풀이**  
> **합의적 커넥톰(consensus connectome)**: 여러 관측자료를 결합해 대표적인 연결구조로 구성한 지도.  
> **육각 격자 열(column)**: 시야의 한 위치에 대응하는 반복적인 신경 처리 단위.  
> **연결 부호**: 입력이 다음 뉴런의 활동을 높이는 방향인지, 낮추는 방향인지를 표시하는 값.

### 4.2 전체 처리 구조

모델의 정보 흐름을 정리하면 다음과 같습니다.

$$
X[0:n]
\longrightarrow
\text{광수용체 R1--R8}
\longrightarrow
\text{커넥톰 제약 순환 회로}
\longrightarrow
\text{순간 활동 디코더}
\longrightarrow
\widehat{Y}[n].
$$

여기서 $X[0:n]$은 현재까지의 영상 입력, $\widehat{Y}[n]$은 현재 시점의 광학 흐름 예측입니다.

**[저자 보고]** 시각회로는 피드백 연결을 포함하는 순환망이고, 디코더는 34개 출력 세포 유형의 활동을 받아 광학 흐름으로 변환하는 두 층 공간 합성곱망입니다. 디코더에는 시간 구조가 없으므로, 움직임에 필요한 과거 정보는 시각회로의 동역학에 표현되어야 합니다〔p. 3; Methods pp. 11–12〕. s41586-024-07939-3 s41586-024-07939-3

**중요한 파라미터 집계:** 734개는 **시각회로 부분**의 학습 파라미터입니다. Extended Data Fig. 2에는 디코더의 파라미터가 별도로 표시되어 있으므로, 이를 전체 학습 시스템의 총 파라미터 수로 사용하면 안 됩니다〔p. 17〕. s41586-024-07939-3

> **용어 풀이**  
> **순환 신경망**: 이전 상태와 되먹임 연결이 현재 반응에 영향을 주는 신경망.  
> **합성곱**: 여러 위치에 같은 계산 규칙을 적용하는 연산.  
> **디코더**: 뉴런 활동 형태의 내부 표현을 과제의 정답 형식으로 변환하는 모델.

### 4.3 뉴런의 시간적 동역학 — 원문 식 (1)

```math
\tau_{t_i}\frac{dV_i}{dt}
=
-V_i
+
\sum_j s_{ij}
+
V_{t_i}^{\text{rest}}
+
e_i.
```

**기호 설명**

- $i,j$: 각각 시냅스 후 뉴런과 시냅스 전 뉴런.
- $t_i$: 뉴런 $i$의 **세포 유형**으로, 시간 변수가 아닙니다.
- $V_i$: 뉴런 $i$의 모델 막전위.
- $\tau_{t_i}$: 해당 유형의 막전위 변화 시간상수.
- $V_{t_i}^{\text{rest}}$: 해당 유형의 휴지막전위.
- $s_{ij}$: 뉴런 $j$가 뉴런 $i$에 주는 시냅스 입력항.
- $e_i$: 외부 입력으로, 광수용체에는 영상 입력이 들어가고 다른 유형에서는 0입니다.

**[저자 보고]** 같은 세포 유형은 시간상수와 휴지막전위를 공유합니다. 대부분의 뉴런은 단일 전기 구획으로 모델링하지만, 넓게 분포하는 CT1은 국소 구획으로 나누어 표현합니다〔p. 3; Methods p. 10〕. s41586-024-07939-3 s41586-024-07939-3

**[해석]** 이 식은 입력을 시간에 걸쳐 누적하되, 입력이 없으면 휴지막전위 쪽으로 되돌아가는 구조입니다. 과제 학습은 연결을 새로 자유롭게 만드는 대신, **어떤 세포 유형이 얼마나 빠르게 반응하고 어느 수준에서 작동할지**를 조정합니다.

> **용어 풀이**  
> **시간상수**: 반응이 변하는 속도를 결정하는 값으로, 일반적으로 클수록 변화가 느립니다.  
> **휴지막전위**: 외부 입력이 없는 상태에서 돌아가려는 기준 전위.  
> **단일 구획 모델**: 뉴런의 복잡한 모양을 하나의 전압 상태로 근사하는 모델.  
> **비발화 모델**: 개별 스파이크를 생성하지 않고 연속적인 전압 변화를 계산하는 모델.

### 4.4 시냅스 입력과 커넥톰 제약 — 원문 식 (2)

```math
s_{ij}
=
w_{ij}f(V_j)
=
\alpha_{t_i t_j}
\sigma_{t_i t_j}
N_{t_i t_j\Delta u\Delta v}
f(V_j),
```

$$
f(V)=\max(V,0).
$$

**기호 설명**

$\alpha_{t_i t_j}\ge 0$는 세포 유형 쌍별로 학습하는 단위 시냅스 강도 계수이고, $\sigma_{t_i t_j}\in\{-1,+1\}$는 고정된 연결 부호입니다. $N_{t_i t_j\Delta u\Delta v}$는 해당 세포 유형 쌍과 상대 위치에서 커넥톰으로 추정한 시냅스 수이며, $\Delta u=u_i-u_j$, $\Delta v=v_i-v_j$는 육각 격자에서의 상대 위치입니다. $w_{ij}$는 이 요소를 곱한 유효 연결 강도이고, $f$는 음수 전압 범위의 출력을 0으로 만드는 임계선형 함수입니다〔Methods p. 10〕. s41586-024-07939-3

**[해석]** 같은 유형의 뉴런 쌍끼리는 시냅스 수가 두 배이면 연결 강도도 두 배라고 가정합니다. 그러나 서로 다른 유형 쌍은 다른 $\alpha$를 가지므로, 같은 시냅스 수라도 유효 강도가 다를 수 있습니다. 이 가정이 강력한 파라미터 절약의 원천인 동시에, 실제 시냅스 간 이질성을 제한하는 근사입니다. s41586-024-07939-3

> **용어 풀이**  
> **임계선형 함수/ReLU**: 임계값 아래에서는 0, 위에서는 입력에 비례하는 출력을 내는 함수.  
> **연속적 전달물질 방출(graded release)**: 스파이크 유무만이 아니라 막전위 수준에 따라 시냅스 출력이 달라지는 방식.  
> **파라미터 공유**: 여러 뉴런이나 연결에서 같은 학습값을 재사용하여 자유도를 줄이는 방법.

### 4.5 어떻게 734개로 줄어드는가?

원문 Methods의 집계를 따르면 다음과 같습니다.

```math
P_{\text{DMN}}
=
2T+Q
=
2\times65+604
=
734.
```

$T=65$는 모델에서 구분하는 집단 수이며, 실제 64개 세포 유형 중 CT1의 medulla·lobula 구획을 따로 집계하기 때문에 65가 됩니다. $Q=604$는 연결된 세포 유형 쌍의 수입니다. 따라서 65개 휴지막전위, 65개 시간상수, 604개 단위 시냅스 강도를 학습합니다〔Methods pp. 10–11〕. s41586-024-07939-3 s41586-024-07939-3

**[해석]** 이 절약은 커넥톰만의 효과가 아니라 **세포 유형 분류, 공간적 반복성, 공유 동역학, 시냅스 수에 대한 비례 가정**이 함께 만든 결과입니다. 따라서 다른 회로에서 같은 수준의 파라미터 절약이 가능한지는 별도의 문제입니다.

### 4.6 학습 목적함수와 안정화

현재 상태의 출력 뉴런 활동을 디코딩하는 관계는 다음과 같이 쓸 수 있습니다.

```math
\widehat{Y}[n]
=
D_{\phi}
\left(
[V_{\theta}[n]]_{\text{out}}^{+}
\right).
```

$\theta$는 시각회로 파라미터, $\phi$는 디코더 파라미터, $\text{out}$은 디코더에 연결되는 뉴런 집합, $+$는 정류를 뜻합니다.

원문에 표시된 과제 손실식은 다음의 L2 거리입니다.

```math
\mathcal{L}(Y,\widehat{Y})
=
\|Y-\widehat{Y}\|_2.
```

$Y$는 정답 광학 흐름입니다. 저자들은 시간 역전파를 통해 시각회로와 디코더를 함께 최적화했습니다〔Methods p. 11〕. **재현상 주의:** 같은 페이지의 산문에는 “square error loss”라는 표현도 있어, 제곱 여부와 배치·시간·공간 차원의 축약 방식까지 이 표시식만으로 확정해서는 안 됩니다. s41586-024-07939-3 s41586-024-07939-3

또한 휴지막전위에는 활동이 모두 사라지거나 지나치게 커지는 것을 막는 별도 정규화를 적용했습니다.

```math
\overline{V}_{bq}
=
\frac{1}{N_f}
\sum_{n=1}^{N_f}
V_{b,q,\text{central}}[n],
```

```math
\mathcal{R}(V)
=
\frac{\lambda_V}{BT}
\sum_{b=1}^{B}
\sum_{q=1}^{T}
\begin{cases}
\gamma(\overline{V}_{bq}-a)^2,
& \overline{V}_{bq}\le a,\\
\delta(\overline{V}_{bq}-a)^2,
& \overline{V}_{bq}>a.
\end{cases}
```

여기서 $B$는 배치 크기, $T$는 모델 집단 수, $N_f$는 시간 스텝 수, $\text{central}$은 중앙 열의 뉴런입니다. 원문은 $\lambda_V=0.1$, $a=5$, $\gamma=1$, $\delta=0.01$을 사용합니다. 위 식에서는 시간 인덱스와 혼동하지 않도록 세포 집단 인덱스를 $q$로 바꿨습니다〔Methods p. 11〕. s41586-024-07939-3

> **용어 풀이**  
> **시간 역전파(BPTT)**: 과거 상태가 현재 오차에 미친 영향을 시간축을 따라 거슬러 계산하는 학습법.  
> **정규화(regularization)**: 목표 오차만 줄이다가 비현실적이거나 과도하게 복잡한 해법에 도달하지 않도록 추가하는 제약.  
> **정류**: 여기서는 음수 활동을 0으로 처리하는 연산.

**[해석]** “활동 데이터를 학습하지 않았다”는 설명은 맞지만, 활동에 대한 모든 가정이 사라진 것은 아닙니다. 활동이 유지되고 폭주하지 않도록 하는 정규화 자체도 모델 해 공간을 제한합니다. 또한 BPTT를 사용했다는 사실은 초파리 뇌가 실제로 같은 방식으로 학습한다는 주장이 아닙니다.

### 4.7 학습자료와 일반화 장치

**[저자 보고]** 저자들은 Sintel 애니메이션의 23개 시퀀스를 사용하고, 영상을 흑백 육각 격자로 변환했습니다. 학습에는 20 ms 시간 간격을 사용했으며, 반전·회전·잡음·밝기·대비 변화와 공간적 부분 추출을 적용했습니다. 같은 장면에서 잘라낸 부분들이 학습·검증 집합 양쪽에 들어가지 않도록 했습니다〔Methods pp. 11–12〕. s41586-024-07939-3

**[해석]** 이는 장면 중복에 따른 누출을 줄이는 적절한 조치입니다. 그러나 동일 데이터셋 내 장면 일반화와, 실제 초파리가 비행하며 경험하는 시각환경으로의 일반화는 구별해야 합니다.

## 5. 성능을 무엇으로 측정했는가?

### 5.1 광학 흐름 오차: EPE

```math
\text{EPE}
=
\frac{1}{N_fC}
\sum_{n=1}^{N_f}
\sum_{c=1}^{C}
\sqrt{
\left(y_{1c}[n]-\widehat{y}_{1c}[n]\right)^2
+
\left(y_{2c}[n]-\widehat{y}_{2c}[n]\right)^2
}.
```

$C$는 시야 열의 수, $N_f$는 시간 스텝 수, $y_{1c},y_{2c}$는 정답 운동 벡터의 두 성분이며, 모자 기호는 예측값입니다. 이는 **과제 수행 성능**이지 신경반응의 생물학적 정확도가 아닙니다〔Methods p. 12〕. s41586-024-07939-3

### 5.2 대비 선호: FRI

원문의 정의를 간단한 표기로 옮기면 다음과 같습니다.

```math
\text{FRI}_{q}
=
\frac{\rho_q(1)-\rho_q(0)}
{\rho_q(1)+\rho_q(0)}.
```

$\rho_q(I)$는 원문 방식으로 비음수가 되도록 이동시킨 중앙 뉴런의 최고 전압 반응이고, $I=1$은 ON flash, $I=0$은 OFF flash입니다. 양수는 ON 선호, 음수는 OFF 선호를 나타냅니다〔Methods p. 12〕. s41586-024-07939-3

**[저자 보고]** 이 지표는 밝기 증가와 감소 모두에 반응하는 뉴런의 특성을 완전히 표현하지 못합니다. 따라서 FRI의 정답 여부는 세포 기능의 제한된 한 측면에 대한 평가입니다. s41586-024-07939-3

### 5.3 방향선택성: DSI

원문의 속도·대비 정규화를 보존하면 다음과 같습니다.

```math
\text{DSI}_{q}(I)
=
\frac{1}{|\mathcal{S}|}
\sum_{s\in\mathcal{S}}
\frac{
\left|
\sum_{\vartheta\in\Theta}
r_q^{\text{peak}}(I,s,\vartheta)
\exp(\mathrm{i}\vartheta)
\right|
}{
\max_{I'\in\{0,1\}}
\left|
\sum_{\vartheta\in\Theta}
r_q^{\text{peak}}(I',s,\vartheta)
\right|
}.
```

$r_q^{\text{peak}}$는 정류된 최고 전압 반응, $\Theta$는 12개 이동 방향, $\mathcal{S}$는 6개 이동 속도, $\mathrm{i}$는 허수 단위입니다. 방향별 반응을 벡터로 합쳐 한 방향으로 얼마나 모이는지를 측정하고, 두 대비 조건의 반응 크기를 함께 고려하여 정규화합니다〔Methods p. 13〕. s41586-024-07939-3

> **용어 풀이**  
> **튜닝(tuning)**: 자극의 방향·속도·밝기 등에 따라 뉴런 반응이 달라지는 패턴.  
> **FRI**는 밝아짐과 어두워짐 중 선호를, **DSI**는 특정 이동 방향에 대한 선택성을 요약합니다.  
> 논문마다 정규화가 다를 수 있으므로, 지표 이름이 같다는 이유만으로 수치를 직접 비교해서는 안 됩니다.

### 5.4 무엇이 향상되었고, 무엇은 향상되었다고 말할 수 없는가?

**[저자 보고]** 과제 최적화는 무작위 파라미터 DMN과 디코더 단독 모델보다 과제 수행을 개선했고, 상세 커넥톰 제약은 세포별 생물학적 반응 예측을 개선했습니다. 그러나 Extended Data Fig. 2a에서 비제약 CNN은 Full DMN보다 낮은 과제 오차를 보입니다〔pp. 3, 17〕. s41586-024-07939-3 s41586-024-07939-3

**[해석]** 따라서 이 연구의 주된 성능 향상은 **정확한 세포 대응과 생물학적 예측력**에 있습니다. 일반 컴퓨터 비전 모델보다 광학 흐름을 더 정확하게 추정하거나, 같은 정확도에 더 적은 학습자료가 필요하다는 보편적 우월성은 입증하지 않았습니다.

## 6. 가장 중요한 그림의 해석

### Fig. 1 — 구조·동역학·과제라는 세 수준을 묶는 설계

**[저자 보고]** Fig. 1c–e는 어떤 유형이 어느 상대 위치에서 연결되는지 보여주고, Fig. 1f는 뉴런·시냅스 방정식, Fig. 1g는 영상에서 광학 흐름으로 이어지는 학습 구조를 제시합니다〔p. 2〕. s41586-024-07939-3

**확인 범위:** Beiran·Litwin-Kumar 연구의 위 설명은 출판사 초록과 공개된 그림 제목, 2026년 크기 일반화 연구의 수치는 출판사 초록에서 확인되는 내용에 한정했습니다. 접근되지 않은 본문의 추가 실험이나 상세 통계는 추정하여 보충하지 않았습니다.

### 8.2 일반화 관점에서 가장 중요한 변화

**첫째, 구조가 있다는 사실보다 어떤 미지수가 남는지가 중요합니다.**  
본 논문의 Fig. 5는 희소성이 도움을 줄 수 있음을 보여주지만, Beiran·Litwin-Kumar 연구는 연결 강도가 같아도 미지의 생물물리 파라미터 때문에 순환망 동역학이 달라질 수 있음을 강조합니다. **[해석]** 따라서 “더 상세한 커넥톰이면 충분하다”보다, 구조 측정과 활동 측정이 어떤 불확실성을 각각 줄이는지 따져야 합니다. s41586-024-07939-3 [Nature](https://www.nature.com/articles/s41593-025-02080-4)

**둘째, 공간 일반화에는 입력 센서의 기하학도 포함됩니다.**  
Zhao et al.의 결과는 시야 위치별 선호 방향 변화가 눈 구조와 연결된다는 점을 보여줍니다. **[후속 연구 제안]** 가중치 공유를 전면 폐기하기보다, 실제 눈의 좌표계에서는 공유 규칙을 유지하고 외부 시각공간으로의 변환을 더 정확하게 만드는 접근을 우선 시험할 가치가 있습니다. [PubMed](https://pubmed.ncbi.nlm.nih.gov/40702177/)

**셋째, ‘정보가 남아 있는가’와 ‘원래 회로가 그대로 읽어낼 수 있는가’는 다릅니다.**  
2026년 크기 일반화 연구에서는 T4/T5를 억제했을 때 디코더를 다시 맞추면 높은 방향 정보 추출 성능이 남지만, 기존 디코더를 고정하면 성능이 크게 떨어지는 결과도 보고했습니다. **[해석]** 후속 모델의 회로 조작 실험에서는 **디코더 고정 평가와 재학습 평가를 분리**해야 하며, 재학습 후 회복을 즉각적인 생물학적 기능 보존으로 해석하면 안 됩니다. [Springer](https://link.springer.com/article/10.1007/s12021-026-09811-3)

## 9. 모델의 일반화 성능을 어떻게 개선할 수 있는가?

### 9.1 먼저 ‘일반화’를 네 가지로 나누어야 한다

| 일반화의 종류 | 본 논문에서 확인된 범위 | 아직 필요한 검증 |
|---|---|---|
| **새로운 자극에 대한 일반화** | 학습에 쓰지 않은 Sintel 검증 장면과, 별도 단순 자극의 신경 튜닝 평가가 있습니다. | 실제 자연영상, 극단적인 속도·대비·크기, 장시간 자극에 대한 분포 밖 평가. |
| **활동을 학습하지 않은 뉴런의 기능 예측** | 과제 학습만으로 알려진 여러 세포 유형의 기능을 예측합니다. | 활동이 아직 알려지지 않은 유형에 대한 사전 예측과 후속 생체 검증. |
| **개체·성별·커넥톰 간 일반화** | 여러 자료를 합친 대표 회로를 모델링합니다. | 특정 개체로 학습하고 다른 개체의 구조·활동을 예측하는 검증. |
| **새 과제·행동·개입에 대한 일반화** | 주된 학습 과제는 광학 흐름입니다. | 다른 시각 과제, 행동 상태 변화, 세포 조작 후 반응에 대한 독립 검증. |

앞의 두 항목은 원문의 검증 설계에 근거하지만, 뒤의 두 항목에 대한 포괄적 성능은 이 논문에서 보고되지 않았습니다〔pp. 3, 8; Methods pp. 11–12〕. s41586-024-07939-3 s41586-024-07939-3 s41586-024-07939-3

> **용어 풀이**  
> **분포 밖 일반화(OOD generalization)**: 학습자료와 종류·범위·발생 조건이 다른 입력에서도 성능을 유지하는 능력.  
> 단순한 학습/검증 분할을 통과했다고 해서 모든 종류의 분포 밖 일반화가 확인되는 것은 아닙니다.

### 9.2 최우선 방향: 소량의 신경활동 자료를 선택적으로 추가

**[저자 제안]** 원문은 소량의 활동 측정으로 모델을 추가 제약하거나 활동·행동 자료에 직접 맞추는 방향을 제시합니다. Fig. 3은 T4c에 관한 정보를 이용해 Mi4·Mi9의 가능한 반응까지 좁힐 수 있음을 보여줍니다〔pp. 5, 8〕. s41586-024-07939-3 s41586-024-07939-3

**[후속 연구 제안]** 무작위로 많은 뉴런을 기록하기보다, 서로 다른 모델 군집이 상반된 예측을 하는 뉴런·자극 조합을 우선 측정하는 방식이 유망합니다. Tm4의 실패 원인, TmY3의 독립적 운동 검출 가능성, T4 측방 연결의 역할처럼 경쟁 가설을 구분할 수 있는 지점을 우선순위로 삼을 수 있습니다.

평가에서는 추가 학습에 사용한 뉴런·자극과 최종 검증에 사용한 뉴런·자극을 분리해야 합니다. 측정한 뉴런만 더 잘 맞추는 것이 아니라, **측정하지 않은 뉴런의 예측도 좋아졌는지**가 핵심입니다.

### 9.3 다중 과제·활동·구조 불확실성을 함께 다루는 목적함수

다음은 **원문 수식이 아니라 후속 연구를 위한 제안식**입니다.

```math
\mathcal{L}_{\text{joint}}
=
\sum_{k=1}^{K}
\lambda_k\mathcal{L}_{\text{task},k}
+
\lambda_{\text{neural}}
\sum_{i\in\mathcal{O},n}
\left\|
h_i(V_i[n])-y_i[n]
\right\|_2^2
+
\lambda_{\text{conn}}\mathcal{R}_{\text{conn}}
+
\lambda_{\text{dyn}}\mathcal{R}_{\text{dyn}}.
```

**기호 설명**

$K$는 과제 수, $\mathcal{L}\_{\text{task},k}$는 각 과제의 손실, $\mathcal{O}$는 활동을 실제로 측정한 뉴런 집합, $y_i[n]$는 측정값입니다. $h_i$는 모델 전압을 측정 신호로 바꾸는 관측 모델이며, $\mathcal{R}\_{\text{conn}}$은 연결·시냅스 정보와의 불일치를 제어하고, $\mathcal{R}_{\text{dyn}}$은 비현실적인 동역학을 억제합니다. 각 $\lambda$는 항의 중요도를 조절합니다.

**[해석 및 제안]** 중요한 점은 칼슘 신호를 전압과 동일시하지 않고 측정 과정 $h_i$를 구분하며, 광학 흐름에 더해 접근 물체 탐지나 물체 추적처럼 관련된 과제를 추가하는 것입니다. 다만 과제를 늘리거나 관측 모델을 유연하게 만들면 오히려 새로운 비식별성이 생길 수 있으므로, 독립 검증에서의 개선으로 채택 여부를 판단해야 합니다.

> **용어 풀이**  
> **관측 모델**: 실제 신경 상태가 측정 장치에서 어떤 신호로 나타나는지를 설명하는 모형.  
> **다중 과제 학습**: 하나의 내부 회로가 여러 과제를 함께 수행하도록 학습하는 방식.  
> 여러 과제의 요구가 충돌하면 성능이 나빠질 수도 있으므로, 과제 추가 자체가 개선을 보장하지는 않습니다.

### 9.4 생물물리적 복잡성은 필요한 곳부터 늘려야 한다

**[저자 제안]** 원문은 전기 시냅스, 비선형 화학 시냅스, 신경조절, 가소성과 더 다양한 생태학적 과제를 향후 확장 방향으로 제시합니다〔Discussion p. 8〕. s41586-024-07939-3

**[후속 연구 제안]** 모든 뉴런을 한 번에 정교하게 만드는 대신, 현재 모델이 실패하는 반응부터 설명해야 합니다. 예를 들어 Tm4의 시간 반응 실패가 입력 연결 누락, 시냅스 시간 특성, 세포 자체의 동역학 중 무엇 때문인지 구분한 뒤 해당 요소만 추가하는 방식입니다.

Groschner et al.의 결과를 고려하면, T4에서 전도도 변화와 억제 해제를 반영하는 확장이 특히 검토할 만합니다. 그러나 더 복잡한 모델이 더 생물학적으로 보인다는 이유만으로 우수하다고 판단하지 말고, **새 자극과 새로운 조작 조건에 대한 예측 개선**을 확인해야 합니다. [Nature](https://www.nature.com/articles/s41586-022-04428-3)

### 9.5 커넥톰을 완전히 고정하는 것과 완전히 자유롭게 학습하는 것 사이

**[후속 연구 제안]** 연결 누락, 시냅스 수 오차, 부호 추정의 불확실성을 무시한 채 하나의 구조만 고정하면, 구조 오차를 시간상수나 휴지막전위가 대신 보상할 수 있습니다. 반대로 모든 연결을 자유롭게 학습하면 이 논문의 가장 중요한 장점인 강한 구조적 제약을 잃습니다.

따라서 신뢰도가 높은 연결은 강하게 고정하고, 불확실한 연결은 제한된 변동을 허용하는 **확률적 또는 계층적 제약**을 비교할 필요가 있습니다. 세포 유형의 공통값을 유지하면서 개체별·국소적 차이를 작게 허용하는 모델을, 완전 공유 모델과 동일 검증조건에서 비교하는 것이 적절합니다.

> **용어 풀이**  
> **계층적 모델**: 집단 전체가 공유하는 특성과 개별 대상의 차이를 함께 표현하는 모델.  
> 이 경우 “같은 세포 유형이면 대체로 비슷하지만 완전히 같지는 않다”는 가정을 구현할 수 있습니다.

### 9.6 성능 개선을 주장하기 위한 최소 비교 설계

**[후속 연구 제안]** 향후 연구에서는 다음 항목을 같은 실험 안에서 분리해 보고하는 것이 중요합니다.

| 비교 축 | 권장 검증 |
|---|---|
| **학습자료 일반화** | 장면뿐 아니라 자극 크기·속도·환경을 통째로 제외한 평가를 수행합니다. |
| **신경활동 일반화** | 추가 측정자료로 학습하지 않은 세포 유형과 자극에서 예측 개선을 확인합니다. |
| **구조의 기여** | 세포 유형, 연결 수, 흥분·억제 비율 등을 통제한 무작위 구조와 비교합니다. |
| **모델 예산의 공정성** | 디코더까지 포함한 파라미터 수, 시간 입력 범위, 학습량을 명시합니다. |
| **개입의 의미** | 뉴런 억제 후 디코더를 고정하는 평가와 재학습하는 평가를 구분합니다. |
| **통계적 신뢰성** | 프레임 수가 아니라 장면·개체·독립 학습 실행 같은 적절한 단위에서 변동성과 신뢰구간을 평가합니다. |

이 설계의 목표는 과제 점수 하나의 개선이 아니라, **자극·세포·개체·개입이라는 여러 축에서 유지되는 예측력**을 확인하는 것입니다.

## 11. 결론: 저자의 시사점과 추가 연구 방향

### 저자들이 제시한 시사점과 후속 방향

**[저자 보고]** 이 연구는 미시적인 연결정보와 거시적인 계산 과제를 함께 사용하면, 많은 뉴런을 포함하는 회로에서도 세포별로 시험 가능한 예측을 만들 수 있음을 보여줍니다. 저자들은 이 모델을 완결된 뇌 복원 결과보다 **발견과 가설 생성의 도구**로 제시하며, 소량의 신경활동·행동 측정을 추가하거나 더 정교한 뉴런·시냅스·조절 메커니즘을 도입하는 방향을 제안합니다〔Discussion p. 8〕. s41586-024-07939-3 s41586-024-07939-3

또한 전체 시각계·전체 신경계 연결자료와 전사체·활동·행동 자료를 통합하고, 장기적으로는 신체의 생체역학 모델과 결합한 전동물 모델을 전망합니다. 이는 논문이 제시한 **연구 방향**이며, 각 단계가 이미 검증되었거나 구체적인 완료 일정이 제시된 것은 아닙니다〔pp. 8–9〕. s41586-024-07939-3

### 추가 평가와 가장 우선할 후속 연구

**[해석]** 가장 큰 기여는 인공신경망과 생물학적 회로의 비교를 “어느 층이 어느 뇌 영역과 비슷한가”에서 **“이 세포와 이 연결이 어떤 반응을 만들어야 하는가”**라는 구체적인 수준으로 옮겼다는 점입니다. 반면 현재 증거는 선택된 운동 시각 특성의 예측을 강하게 지지하지만, 전체 시각 기능·개체 차이·새로운 행동으로의 일반화를 확정하지는 않습니다. s41586-024-07939-3

**[후속 연구 제안]** 일반화 성능을 높이기 위한 최우선 조합은 다음과 같습니다.

> **더 넓고 현실적인 자극 분포 + 모델 간 차이를 구분하는 소량의 신경활동 측정 + 연결 불확실성의 명시적 처리 + 개체·자극·개입을 분리한 독립 검증.**

단순히 모델을 더 크게 만들거나 과제 오차를 더 낮추는 것보다, **추가하지 않은 자료에서도 유지되는 세포별 예측력과 조작 후 반응의 정확도**를 개선 기준으로 삼는 것이 이 논문의 기여를 가장 생산적으로 발전시키는 방향입니다.
