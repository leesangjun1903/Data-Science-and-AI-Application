저자들은 72큐비트 Willow 프로세서에서 데이터 큐비트 19개와 보조 큐비트 18개로 거리 5의 논리 큐비트를 구현했습니다. **[p.615, Fig.1]** s41586-025-09061-4 s41586-025-09061-4

> **용어:** 논리 큐비트는 여러 물리 큐비트에 분산해 저장한 하나의 보호된 정보 단위이고, 코드 거리는 검출되지 않는 논리 오류를 일으키는 데 필요한 최소 물리 오류 수입니다.

## 2. 연구의 목적과 필요성

### 2.1 해결하려는 문제: “오류가 적은 메모리”만으로는 충분하지 않다

**[저자의 문제 설정]** 양자 오류정정은 여러 물리 큐비트로 하나의 논리 큐비트를 구성해 오류를 줄이는 방법입니다. 하지만 실용적 양자 계산에는 정보를 오래 저장하는 것뿐 아니라, **오류를 확산시키지 않으면서 논리 게이트를 낮은 비용으로 실행하는 능력**도 필요합니다. 저자들은 표면 코드가 높은 오류 임계값과 평면 배치라는 장점을 갖지만, 일부 논리 연산과 자원 비용에서는 제약이 있다는 점에 주목합니다. **[p.614]** s41586-025-09061-4

> **용어 — 오류 임계값:** 물리 오류가 충분히 작아서, 코드를 크게 만들수록 논리 오류가 감소하기 시작하는 경계입니다.  
> **용어 — 내결함성:** 일부 물리적 고장이 발생해도 그것이 복구 불가능한 논리 오류로 쉽게 확산되지 않도록 설계된 성질입니다.

컬러 코드의 매력은 같은 코드 거리에서 더 적은 큐비트를 사용하고, 단일 큐비트 Clifford 연산을 효율적으로 구현할 수 있다는 데 있습니다. 반면, 더 많은 큐비트가 참여하는 안정자 측정과 복잡한 디코딩이 필요해 하드웨어 요구가 까다롭습니다. **[p.614]** s41586-025-09061-4

> **용어 — 안정자(stabilizer):** 저장된 양자 정보를 직접 읽지 않으면서, 오류가 발생했는지 확인하는 검사 연산자입니다.  
> **용어 — 디코더(decoder):** 여러 오류 검사 결과를 조합해 어떤 논리적 보정이 필요한지 추론하는 고전 알고리즘입니다.

## 4. 방법과 구조: 수식으로 이해하기

### 4.1 양자 코드 구조와 하드웨어 배치

**[저자·방법]** 각 격자 면에는 $X$형과 $Z$형 안정자가 하나씩 존재합니다. 내부 육각형에는 6개 데이터 큐비트가, 경계의 사각형에는 4개가 참여합니다. 거리 5 코드에는 무게 6 안정자 6개와 무게 4 안정자 12개가 있습니다. **[p.615, Fig.1a–c]** s41586-025-09061-4

이를 설명용 수식으로 쓰면 다음과 같습니다.

$$
S_f^X=\prod_{j\in V(f)}X_j,
\qquad
S_f^Z=\prod_{j\in V(f)}Z_j.
$$

**기호 설명:** $f$는 격자 면, $V(f)$는 그 면의 꼭짓점에 놓인 데이터 큐비트 집합, $X_j$와 $Z_j$는 큐비트 $j$에 작용하는 Pauli 연산자입니다. $S_f^X$와 $S_f^Z$는 해당 면의 오류 검사 연산자이며, $\prod$는 서로 다른 큐비트에 작용하는 연산자의 곱을 뜻합니다.

> **용어 — 안정자의 무게(weight):** 검사에 참여하는 데이터 큐비트의 수입니다.  
> **용어 — Pauli 연산자:** $X$는 비트 반전, $Z$는 상대 위상 반전, $Y$는 두 효과가 결합된 기본 양자 연산자입니다.

논리 연산자는 삼각형 경계에 놓인 데이터 큐비트들의 연산자로 표현됩니다.

$$
X_L=\prod_{j\in B}X_j,
\qquad
Z_L=\prod_{j\in B}Z_j.
$$

**기호 설명:** $B$는 선택한 삼각형 경계의 데이터 큐비트 집합이며, 아래첨자 $L$은 개별 물리 큐비트가 아니라 **논리 큐비트 전체**에 대한 연산임을 나타냅니다. **[p.615, Fig.1c]** s41586-025-09061-4

#### 측정을 가능하게 만든 회로

각 내부 면의 보조 큐비트 두 개를 Bell 쌍으로 준비하고, 주변 데이터 큐비트와 상호작용시킨 뒤 Bell 기저로 읽어 $X$형 · $Z$형 안정자 정보를 얻습니다. 이것이 논문에서 사용하는 **superdense syndrome extraction**의 핵심입니다. **[p.615, Fig.1a,b]** s41586-025-09061-4

> **용어 — Bell 쌍:** 두 큐비트의 측정 결과가 양자적으로 강하게 연결된 얽힘 상태입니다. 여기서는 두 종류의 오류 검사 정보를 효율적으로 추출하는 보조 자원으로 사용합니다.

실제 칩에서는 같은 판독선에 연결된 큐비트들의 측정 시점이 중요한 제약입니다. 저자들은 일부 데이터·보조 큐비트의 **역할을 바꾸고 회로를 변형**해 이 제약에 대응하며, 단순한 SWAP 게이트 분해로 발생할 비용을 피합니다. **[p.615, Fig.1c,d]** s41586-025-09061-4

**[해석]** Fig.1의 중요한 기여는 예쁜 삼각형 격자를 구현했다는 데 있지 않습니다. **추상적인 코드 구조를 칩의 판독 방식에 맞춰 바꾸면서도 오류정정 기능을 유지했다는 것**이 실용적으로 중요합니다.

### 4.2 신드롬 구성과 메모리 오류율 추정

**[저자·방법]** 같은 안정자의 연속한 측정값을 비교해 오류 검출 신호를 만듭니다. 논리 게이트가 없는 메모리 구간의 기본 관계는 다음과 같습니다.

$$
\delta_{f,t}=s_{f,t}\oplus s_{f,t-1}.
$$

**기호 설명:** $s_{f,t}\in\{0,1\}$은 면 $f$의 사이클 $t$에서 얻은 안정자 측정 비트이며, $\oplus$는 배타적 논리합입니다. $\delta_{f,t}=1$이면 두 측정 사이에 변화가 검출되었다는 뜻입니다. **[p.615]** s41586-025-09061-4

> **용어 — 신드롬(syndrome):** 여러 오류 검사에서 얻은 결과의 패턴입니다. 신드롬이 오류의 위치를 항상 유일하게 알려주는 것은 아니므로 디코딩이 필요합니다.

저자들은 최대 29사이클의 메모리 실험에서 최종 논리 오류 확률을 측정하고, **Fig.2c에 명시된 다음 식**으로 적합합니다.

$$
P_L(n)=\frac12+\varepsilon_0(1-2\varepsilon_d)^n.
$$

**기호 설명:** $P_L(n)$은 $n$사이클 후 최종 논리 측정이 틀릴 확률, $\varepsilon_d$는 거리 $d$ 코드의 사이클당 논리 오류율, $\varepsilon_0$는 초기화·측정 등의 영향을 흡수하는 적합 진폭입니다. **$\varepsilon_0$ 자체를 초기 오류 확률로 해석하면 안 됩니다.** 실제 초기값은 $P_L(0)=1/2+\varepsilon_0$입니다. **[p.616, Fig.2c 설명]** s41586-025-09061-4

**[수식 해석]** 이상적으로 초기 오류가 없다면 $\varepsilon_0=-1/2$입니다. 이 식은 오류가 누적되면서 최종 비트가 맞거나 틀릴 확률이 $1/2$에 가까워지는 형태이며, “실행 도중 한 번이라도 오류가 발생했을 확률”을 직접 나타내지는 않습니다.

거리 증가의 효과는 다음 비율로 평가합니다.

```math
\Lambda_{3/5}
=
\frac{\overline{\varepsilon}_3}{\varepsilon_5}
=
1.56(4).
```

**기호 설명:** $\overline{\varepsilon}_3$는 세 거리 3 부분 코드의 평균 사이클당 오류율이고, $\varepsilon_5$는 거리 5 코드의 오류율입니다. $1.56(4)$는 마지막 자리의 불확실성을 풀어 쓰면 $1.56\pm0.04$입니다. **[p.616]** s41586-025-09061-4

**[직접 계산]** 보고된 억제 인자를 기준으로 한 상대 오류 감소는 $1-1/1.56\approx35.9\%$입니다. 그러나 이 값은 **거리 3→5라는 특정 변화의 효과**이지, 큐비트를 늘릴 때마다 항상 같은 비율로 개선된다는 보장은 아닙니다.

### 4.3 AI 디코더의 구조와 학습

**[저자·방법]** 보충자료 D.1.c에 따르면 AlphaQubit은 합성곱을 제외한 순환 어텐션 구조이며, 1층·2층 변형의 파라미터는 각각 약 210만·410만 개입니다. 안정자별 내부 벡터를 갱신하고, 논리 게이트 벤치마킹에서는 게이트 정보도 입력받습니다. Stim/SI1000 합성데이터로 사전학습한 뒤 실험데이터로 미세조정합니다. **[보충자료 p.10]** [Springer Nature](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09061-4/MediaObjects/41586_2025_9061_MOESM1_ESM.pdf)

> **용어 — 순환 구조:** 이전 시점의 정보를 내부 상태에 저장해 다음 시점의 추론에 사용하는 구조입니다.  
> **용어 — 어텐션:** 여러 검사 결과 중 서로 관련성이 큰 정보를 선택적으로 결합하는 연산입니다.  
> **용어 — 사전학습·미세조정:** 많은 합성 사례로 기본 패턴을 학습한 뒤, 실제 장치 자료로 장치 특성에 맞추는 과정입니다.

이 동작을 **설명용 추상식**으로 나타내면 다음과 같습니다. 이는 논문에 번호를 붙여 제시된 원래 학습식이 아니라 구조를 요약한 표현입니다.

```math
h_t=f_{\vartheta}(h_{t-1},\boldsymbol{\delta}_t,g_t),
\qquad
q_{\vartheta}
=
\sigma\!\left(r_{\vartheta}(h_n)\right).
```

**기호 설명:** $h_t$는 사이클 $t$까지의 내부 표현, $\boldsymbol{\delta}\_t$는 해당 사이클의 신드롬 벡터, $g_t$는 적용된 논리 게이트 정보, $\vartheta$는 학습 파라미터입니다. $f_{\vartheta}$는 상태 갱신 함수, $r_{\vartheta}$는 최종 출력 함수, $\sigma$는 값을 0과 1 사이로 변환하는 함수, $q_{\vartheta}$는 논리 판정에 사용하는 예측 확률입니다.

#### 일반화 평가에 중요한 실제 학습 단위

메모리 실험은 **코드 인스턴스·측정 기저별로 별도 모델**을 학습했습니다. 벤치마킹과 순간이동도 각 실험 내부에서 모델을 공유할 뿐, 모든 실험을 하나의 모델로 통합한 것은 아닙니다. 학습·평가는 메모리의 과거→미래 분할, 벤치마킹의 짝수/홀수 실행 분할, 순간이동의 별도 표본 분할로 구분했습니다. **[보충자료 p.10]** [Springer Nature](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09061-4/MediaObjects/41586_2025_9061_MOESM1_ESM.pdf)

**[해석]** 따라서 여기서의 성공은 **장치 데이터에 적응한 디코딩**의 성공입니다. 거리 3에서 학습한 신경망을 재학습 없이 거리 5에 적용해 성공했다는 결과로 읽으면 안 됩니다.

#### AI만이 오류 억제를 가능하게 했는가?

보충자료 Fig.9의 결과는 다음과 같습니다. **[보충자료 p.11]** [Springer Nature](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09061-4/MediaObjects/41586_2025_9061_MOESM1_ESM.pdf)

| 디코더와 사전 잡음 정보 | $\Lambda_{3/5}$ |
|---|---:|
| Chromobius + 일반 SI1000 사전정보 | $0.83(2)$ |
| Chromobius + 실험에서 학습한 사전정보 | $0.93(2)$ |
| MLE + 일반 SI1000 사전정보 | $1.35(5)$ |
| MLE + 실험 기반 재가중 사전정보 | $1.53(4)$ |
| 미세조정한 AlphaQubit | $1.56(4)$ |

여기서 MLE는 **most likely error**이며, 모든 동등한 오류 패턴의 확률을 합산하는 최우도 논리류 디코더와는 다릅니다. 또한 방법별 평가 표본이 완전히 일치하지 않습니다. **[보충자료 pp.9–11]** [Springer Nature](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09061-4/MediaObjects/41586_2025_9061_MOESM1_ESM.pdf)

**[해석]** 이 표에서 가장 중요한 결론은 “AI가 다른 모든 방법을 압도했다”가 아닙니다. **디코더와 잡음 사전정보가 관측되는 확장 성능을 크게 바꾸며, 잘 보정된 비신경망 디코더도 비슷한 억제를 얻는다**는 점입니다. 특히 $1.53(4)$와 $1.56(4)$의 차이만으로 AlphaQubit의 정확도 우위를 통계적으로 확정하기는 어렵습니다.

### 4.4 논리 Clifford 게이트와 벤치마킹

**[저자·방법]** 저자들은 24개의 단일 큐비트 Clifford 게이트를 구현하고, 게이트 사이에 오류정정 사이클을 넣어 성능을 평가합니다. 게이트가 없는 메모리 기준 실험과 비교함으로써 게이트의 **추가 오류**를 추정합니다. **[p.616, Fig.3a]** s41586-025-09061-4

> **용어 — 횡단 게이트(transversal gate):** 논리 블록의 각 데이터 큐비트에 독립적으로 물리 게이트를 적용하는 방식입니다. 단일 큐비트 횡단 연산에서는 한 데이터 큐비트의 오류가 그 연산을 통해 다른 데이터 큐비트로 번지지 않습니다.  
> **용어 — 무작위 벤치마킹(RB):** 무작위 게이트열과 그것을 되돌리는 연산을 실행하고, 길이에 따른 성능 저하로 평균 오류를 추정하는 방법입니다.

게이트가 들어가면 검사 연산자 자체가 변환됩니다. 예를 들어 물리 Pauli 연산자의 기본 변환은 다음과 같습니다.

$$
HXH^\dagger=Z,
\qquad
HZH^\dagger=X,
\qquad
SXS^\dagger=Y.
$$

**기호 설명:** $H$는 Hadamard 게이트, $S$는 위상 게이트이며, $\dagger$는 켤레전치를 뜻합니다. $X,Y,Z$는 Pauli 연산자입니다.

**[해석]** 따라서 게이트 전후에 같은 보조 큐비트의 비트만 무조건 비교하면 안 됩니다. **어떤 게이트가 안정자를 어떻게 바꾸었는지 추적해야 올바른 신드롬을 만들 수 있습니다.** 이것이 Fig.3b–d의 의미입니다. s41586-025-09061-4 s41586-025-09061-4

보충자료의 실제 벤치마킹 식은 다음과 같습니다.

```math
F_{\text{RB}}(m)=A p^m+\frac12,
\qquad
\varepsilon_C
=
\frac12\left(1-\frac{p_C}{p_I}\right).
```

**기호 설명:** $m$은 Clifford 게이트 수, $A$는 적합 진폭, $p_C$와 $p_I$는 각각 게이트 포함 실험과 메모리 기준 실험의 감쇠 파라미터입니다. $\varepsilon_C$는 평균 추가 논리 오류입니다. **[보충자료 p.12, Eq.F1]** [Springer Nature](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09061-4/MediaObjects/41586_2025_9061_MOESM1_ESM.pdf)

**[저자·실험]** 거리 3에서 게이트 수를 0–10개로 바꾸고, 길이마다 25개 무작위 게이트열을 사용했습니다. 결과는 $\varepsilon_C=0.0027(3)$입니다. 물리 게이트 컴파일 과정에서 이웃 오류정정 회로의 단일 큐비트 게이트와 합쳐질 수 있으므로, 이 값은 **그 최적화된 실행 문맥에서의 추가 비용**입니다. **[p.616]** s41586-025-09061-4

**[한계]** 논리 게이트의 오류가 거리 3→5→7에서 감소하는지는 이 실험에서 측정하지 않았습니다. 저자도 이를 후속 연구 목표로 명시합니다. **[p.618]** s41586-025-09061-4

### 4.5 마법 상태 주입: 높은 충실도와 선별 비용

**[저자·방법]** 하나의 물리 큐비트에 원하는 상태를 준비하고, 추가 데이터 큐비트들을 Bell 쌍으로 준비한 뒤 거리 3 코드로 확장합니다. 이 연구가 실험한 것은 **상태 주입**이며, 고충실도 상태를 여러 개 결합하는 전체 증류 프로토콜은 아닙니다. **[pp.616–617, Fig.4a,b]** s41586-025-09061-4 s41586-025-09061-4

> **용어 — 마법 상태(magic state):** Clifford 연산만으로는 부족한 보편적 양자 계산을 가능하게 하는 비Clifford 자원 상태입니다.  
> **용어 — 주입과 증류:** 주입은 물리 상태를 논리 코드 안으로 옮기는 과정이고, 증류는 여러 불완전한 자원 상태를 소비해 더 정확한 상태를 얻는 과정입니다.

목표 논리 상태를 일반적으로 표현하면 다음과 같습니다.

```math
\lvert\psi_L(\theta,\phi)\rangle
=
\cos\frac{\theta}{2}\lvert0_L\rangle
+
e^{i\phi}\sin\frac{\theta}{2}\lvert1_L\rangle.
```

**기호 설명:** $\theta$는 극각, $\phi$는 방위각, $\lvert0_L\rangle$과 $\lvert1_L\rangle$은 논리 계산 기저 상태입니다. $i$는 허수 단위입니다. 이 식은 본문의 각도 매개변수를 표준 상태 표현으로 풀어 쓴 것입니다.

상태 토모그래피로 얻은 논리 상태 $\rho_L$와 순수 목표 상태의 충실도는 다음과 같이 표현할 수 있습니다.

```math
F=\langle\psi_L\rvert\rho_L\lvert\psi_L\rangle
=
\frac{1+\mathbf r_{\text{target}}\cdot\mathbf r_{\text{meas}}}{2},
\qquad
I=1-F.
```

**기호 설명:** $\rho_L$은 재구성한 논리 상태의 밀도행렬, $\mathbf r_{\text{target}}$은 목표 상태의 단위 Bloch 벡터, $\mathbf r_{\text{meas}}$는 측정한 $X_L,Y_L,Z_L$ 기대값으로 구성한 벡터입니다. $F$는 충실도, $I$는 비충실도입니다.

> **용어 — 토모그래피:** 여러 측정 기저에서 반복 측정해 양자 상태를 재구성하는 방법입니다.  
> **용어 — Bloch 벡터:** 한 큐비트 상태를 세 성분으로 표현한 벡터이며, 방향은 상태의 성격을, 길이는 혼합 정도를 나타냅니다.

#### 저자가 보고한 수치와 불확실성

각도 스윕의 평균 비충실도는 디코딩만 적용하면 $0.039(3)$, 오류 검출이 없는 실행을 선별하면 $0.009(4)$였고, 후자의 평균 데이터 유지율은 74.8%였습니다. **[p.617, Fig.4c,d]** s41586-025-09061-4

특정 마법 상태의 결과는 다음과 같습니다. 충실도 구간은 논문이 보고한 **비충실도의 95% 부트스트랩 신뢰구간을 $F=1-I$로 변환한 값**입니다. **[p.617, Fig.4e]** s41586-025-09061-4

| 상태 | 보고된 비충실도 $I$ | 충실도 점추정치 | 변환한 95% 충실도 구간 | 유지율 |
|---|---:|---:|---:|---:|
| $\lvert A_L\rangle$ | $0.0008^{+0.0015}_{-0.0003}$ | 99.92% | 99.77–99.95% | 75.2% |
| $\lvert H_L\rangle$ | $0.0041^{+0.0037}_{-0.0038}$ | 99.59% | 99.22–99.97% | 74.6% |
| $\lvert T_L\rangle$ | $0.0086^{+0.0067}_{-0.0065}$ | 99.14% | 98.47–99.79% | 75.7% |

> **용어 — 부트스트랩:** 측정 표본을 재표집해 추정치의 변동성을 평가하는 통계 방법입니다. 여기서 95% 구간은 물리적 잡음 모델의 모든 불확실성을 포함한다는 뜻은 아닙니다.

**[통계적 주의]** 세 상태의 **점추정치**가 모두 99%를 넘는 것은 맞습니다. 그러나 $\lvert T_L\rangle$의 95% 구간은 99% 아래까지 내려가므로, “세 상태 모두 95% 신뢰수준에서 충실도 99%를 넘는다”고 말할 수는 없습니다.

#### 상태 이름과 정규화에 대한 주의

본문의 $A,H,T$ 상태는 각각 $X+Y$, $X+Z$, $X+Y+Z$ 방향의 양의 고유상태를 가리킵니다. **엄밀하게 $+1$ 고유상태라고 쓰려면 이 연산자들을 각각 $\sqrt2,\sqrt2,\sqrt3$으로 정규화해야 합니다.** 본문의 방향 표현을 정규화한 Bloch 벡터는 다음과 같습니다. **[p.617]** s41586-025-09061-4

$$
\mathbf r_A=\frac{(1,1,0)}{\sqrt2},
\qquad
\mathbf r_H=\frac{(1,0,1)}{\sqrt2},
\qquad
\mathbf r_T=\frac{(1,1,1)}{\sqrt3}.
$$

**기호 설명:** 각 벡터 성분은 순서대로 $X_L,Y_L,Z_L$ 기대값이며, 아래첨자는 이 논문에서 사용한 상태 이름입니다. 따라서 다른 논문에서 “T 상태”라고 부르는 상태와 이름만으로 직접 대응시키면 안 됩니다.

#### 실용성에서 가장 중요한 제한

보충자료는 **최종 데이터 큐비트 판독으로 만든 신드롬도 사후선택에 사용했다**고 명시합니다. **[보충자료 p.13]** [Springer Nature](https://media.springernature.com/original/springer-static/esm/art%3A10.1038%2Fs41586-025-09061-4/MediaObjects/41586_2025_9061_MOESM1_ESM.pdf)

**[해석]** 따라서 높은 선별 후 충실도가 곧바로 **“상태를 파괴하지 않은 채 성공 여부를 알고, 다음 게이트에 공급할 수 있는 자원 상태의 성능”**을 뜻하지는 않습니다. 이 두 성능을 연결하려면, 자원 상태를 유지한 상태에서 사용할 수 있는 검사 정보만으로 같은 품질과 수율을 얻는지 따로 검증해야 합니다.

> **용어 — 사후선택(post-selection):** 측정 결과를 보고 특정 조건을 만족하는 실행만 남기는 방법입니다. 남은 실행의 품질은 좋아질 수 있지만, 버린 실행의 시간·큐비트 비용도 함께 계산해야 합니다.

### 4.6 격자 수술을 통한 논리 상태 순간이동

**[저자·방법]** 첫 논리 큐비트 $L_1$에 입력 상태를, 두 번째 $L_2$에는 $\lvert0_L\rangle$를 준비합니다. 두 코드를 3사이클 동안 병합해 $X_{L_1}X_{L_2}$의 공동 패리티를 측정하고, 1사이클 동안 분리한 뒤 $L_1$을 $Z$ 기저로 측정합니다. **[pp.617–618, Fig.5a–e]** s41586-025-09061-4 s41586-025-09061-4

> **용어 — 격자 수술(lattice surgery):** 인접한 코드의 경계를 잠시 합치고 분리해, 두 논리 큐비트의 공동 정보를 측정하는 방법입니다.  
> **용어 — 양자 순간이동:** 양자 상태의 정보를 측정과 조건부 보정을 통해 다른 큐비트로 옮기는 절차이며, 물질이나 신호를 초광속으로 보내는 현상이 아닙니다.

필요한 논리 보정은 다음과 같습니다.

$$
U_{\text{frame}}=Z_L^{m_1}X_L^{m_2}.
$$

**기호 설명:** $m_1\in\{0,1\}$은 공동 $XX$ 패리티 측정 결과, $m_2\in\{0,1\}$은 $L_1$의 논리 $Z$ 측정 결과입니다. 지수가 0이면 해당 연산을 하지 않고, 1이면 적용한 것으로 처리합니다. 이 연구에서는 이를 **후처리의 Pauli 프레임 갱신**으로 수행했습니다. **[p.618, Fig.5a]** s41586-025-09061-4 s41586-025-09061-4

> **용어 — Pauli 프레임:** 보정 게이트를 매번 물리적으로 가하는 대신, 필요한 보정을 고전적 기록으로 추적하고 이후 측정 결과의 해석에 반영하는 방식입니다.

**[저자·실험]** 입력은 $\lvert0_L\rangle,\lvert1_L\rangle,\lvert+_L\rangle,\lvert-_L\rangle$의 네 상태입니다. 각각의 충실도는 86.5–90.7%이며, 이 측정들로부터 평균 채널 충실도의 하한을 84.7%로 구했습니다. **[p.618, Fig.5f–j]** s41586-025-09061-4

**[해석]** 여기서 84.7%는 정확히 측정한 전체 평균값이 아니라 **하한**입니다. 또한 $Y$축 입력 상태를 포함한 모든 방향을 직접 시험한 것도 아니며, 실시간 조건부 논리 게이트를 통합한 전체 계산 시연과도 구분해야 합니다.

### 7.3 추가 후속 연구 제안

#### A. 실제 코드 구조를 반영하되, 존재하지 않는 대칭성은 강요하지 않는다

**[제안]** 안정자·데이터 큐비트·시간 연결을 그래프로 표현하고, 면의 색·경계 종류·측정 회로 단계·논리 게이트 정보를 입력 특성으로 제공하는 방법을 우선 검토할 가치가 있습니다.

핵심은 “그래프 신경망을 쓰면 된다”가 아닙니다. 같은 국소 구조에는 파라미터를 공유하되, **경계와 병합 인터페이스처럼 역할이 다른 부분은 구분**해야 합니다. 또한 메모리와 격자 수술에서 유지되어야 할 논리적 관계를 검사하는 테스트를 모델 평가에 포함해야 합니다.

#### B. 잡음 세기뿐 아니라 잡음 종류를 바꾸어 학습한다

**[제안]** 합성데이터 생성 시 평균 오류율만 변화시키지 말고, 공간적으로 불균일한 오류, 시간에 따라 변하는 보정값, 지속성 누설, 동시 다중 큐비트 오류, 측정 오류의 상관관계를 함께 변화시키는 것이 필요합니다.

> **용어 — 누설(leakage):** 큐비트가 계산에 사용하는 두 상태 밖으로 벗어나는 오류입니다.  
> **용어 — 드리프트:** 장치 특성이나 제어 오차가 시간에 따라 서서히 바뀌는 현상입니다.  
> **용어 — 도메인 무작위화:** 학습 환경의 여러 조건을 다양하게 바꾸어 특정 환경에만 맞춰지는 것을 줄이는 방법입니다.

설명용으로 다음과 같은 강건 학습 목적함수를 고려할 수 있습니다. **이 식은 제안이며, 대상 논문이 사용했다고 보고한 학습식은 아닙니다.**

```math
\vartheta^\star
=
\underset{\vartheta}{\text{argmin}}
\;
\max_{\eta\in\mathcal U}
\mathbb E_{(\mathbf s,y)\sim P_\eta}
\left[
-y\log q_\vartheta(\mathbf s)
-(1-y)\log\!\left(1-q_\vartheta(\mathbf s)\right)
\right].
```

**기호 설명:** $\vartheta$는 모델 파라미터, $\vartheta^\star$는 선택된 파라미터, $\eta$는 잡음·장치 조건, $\mathcal U$는 고려하는 조건 집합입니다. $P_\eta$는 그 조건의 데이터 분포, $\mathbf s$는 신드롬 입력, $y\in\{0,1\}$은 정답 논리 판정, $q_\vartheta$는 예측 확률, $\mathbb E$는 평균입니다. 식은 여러 조건 중 가장 어려운 조건의 손실까지 줄이려는 목표를 나타냅니다.

**[주의]** 이런 목적함수가 실제 논리 오류율을 얼마나 줄일지는 실험해야 합니다. 학습 손실 감소만으로 물리적으로 중요한 희귀 논리 오류의 감소를 대신 입증할 수 없습니다.

#### C. 새로운 표본보다 “새로운 조건”을 평가 단위로 삼는다

**[제안]** 무작위 표본 분할 외에, 날짜 전체·칩 전체·코드 거리 전체·회로 계열 전체를 평가용으로 남겨두는 설계가 필요합니다. 특히 벤치마킹의 같은 회로를 여러 번 반복한 데이터를 나누는 것과, **한 번도 학습하지 않은 회로를 평가하는 것**을 구분해야 합니다.

장치에 계속 적응시키는 경우에는 업데이트 전후를 동일한 고정 평가셋과 미래 시점 데이터에서 함께 비교해야 합니다. 그렇지 않으면 새로운 조건에 적응하면서 이전 조건의 성능을 잃는 문제를 놓칠 수 있습니다.

#### D. 정확도와 실시간성을 동시에 평가한다

**[외부 연구]** AlphaQubit 2의 실시간 변형은 표면 코드 거리 11, superdense 컬러 코드 거리 9까지 약 $1\,\mu\text{s}$ 사이클 요구에 맞는 처리량을 보고합니다. 그러나 가속기에서의 디코더 평가와 실제 칩의 측정·통신을 포함한 시스템 전체 지연은 구분해야 합니다. **[해당 논문 Fig.4, Methods A.6]** [arXiv](https://arxiv.org/html/2512.07737v2)

**[제안]** 후속 비교에서는 논리 오류율 외에 평균 처리량, 최종 결과 지연, 매우 느린 실행의 비율, 메모리 사용량, 재학습 비용을 함께 측정해야 합니다. 평균 속도가 빠르더라도 드물게 긴 지연이 발생하면 조건부 논리 연산의 병목이 될 수 있습니다.

#### E. 희귀 오류를 검증할 수 있는 표본 설계를 마련한다

**[통계적 도출]** 독립 시행 $N$번에서 실패가 한 번도 없을 때, 실패 확률의 단측 95% 상한은 다음과 같습니다.

```math
p_{\text{upper}}
=
1-0.05^{1/N}
\approx
\frac{3}{N}.
```

**기호 설명:** $N$은 독립 시행 수, $p_{\text{upper}}$는 실패 확률의 상한입니다. 식은 실패가 전혀 없을 확률 $(1-p)^N$을 0.05와 같게 놓아 얻습니다.

따라서 오류 확률 $10^{-8}$ 수준을 “실패 0회”만으로 검증하려면 대략 $3\times10^8$개의 독립 시행이 필요합니다. **상관된 QEC 사이클을 모두 독립 시행으로 세어서는 안 됩니다.** 더 낮은 목표 오류를 평가하려면 희귀 사건 시뮬레이션, 유효 표본 수, 추정 편향을 함께 관리해야 합니다.

### 8.3 연구 흐름에 대한 종합 해석

## 9. 자원 효율을 공정하게 비교하는 방법

**[외부 방법 자료]** 이 삼각형 컬러 코드 배치와 회전 표면 코드의 데이터·보조 큐비트를 합한 수는 다음과 같이 정리됩니다. **[Olle 외, Eqs.10–11]** [arXiv](https://arxiv.org/html/2607.10058v1)

$$
N_{\text{cc}}(d)=\frac{3d^2-1}{2},
\qquad
N_{\text{sc}}(d)=2d^2-1.
$$

**기호 설명:** $N_{\text{cc}}$는 컬러 코드, $N_{\text{sc}}$는 표면 코드의 총 물리 큐비트 수이며, $d$는 각 코드의 거리입니다.

**[직접 계산]** 거리 5에서는 각각 37개와 49개이므로 컬러 코드가 약 24.5% 적습니다. 그러나 **같은 거리에서 더 적은 큐비트를 쓴다는 것과, 같은 목표 논리 오류율에서 더 적은 큐비트를 쓴다는 것은 다릅니다.** 더 낮은 오류 억제 인자를 보상하려고 더 큰 거리가 필요하면 이 이점이 사라질 수 있습니다.

**[제안]** 자원 상태 생성은 다음과 같은 평균 비용도 함께 보고하는 것이 좋습니다.

```math
V_{\text{accepted}}
=
\frac{N_{\text{phys}}\tau}{q},
\qquad
q=\Pr(\text{accept}).
```

**기호 설명:** $N_{\text{phys}}$는 한 시도에 사용하는 물리 큐비트 수, $\tau$는 시도 시간, $q$는 성공·유지 확률, $V_{\text{accepted}}$는 독립적이고 동일한 비용의 시도를 반복한다고 가정했을 때 성공한 자원 하나당 평균 큐비트–시간 비용입니다.

이 비교에는 **같은 목표 출력 오류**, **같은 시점에 실제 사용할 수 있는 검사 정보**, **코드 전환·대기·디코딩 비용**이 적용되어야 합니다. 특히 최종 파괴적 판독에 의존한 유지율을 그대로 실제 자원 생산 수율로 대입해서는 안 됩니다.

## 11. 결론: 저자의 시사점과 추가 연구 방향

### 저자들이 제시한 시사점

**[저자·결론]** 초전도 오류정정의 코드 선택에서 높은 임계값만이 유일한 기준이 되어서는 안 되며, **논리 연산 효율도 중요해지는 단계에 도달했다**는 것이 핵심 메시지입니다. 다만 현재의 표면 코드가 더 좋은 오류 억제를 보인다는 점을 인정하고, 컬러 코드의 잠재적 이점이 실제 알고리즘 비용을 얼마나 줄이는지는 별도의 자원 추정이 필요하다고 말합니다. **[p.618]** s41586-025-09061-4

저자의 후속 목표는 더 크고 정확한 장치, 더 빠르고 정확한 디코더, 코드 크기 증가에 따른 **논리 게이트 오류 감소의 시연**, 컬러 코드 특유의 논리 연산 능력 검증입니다. **[p.618]** s41586-025-09061-4

### AI 연구 관점에서 추가로 우선할 방향

**[제안]** 가장 우선할 연구는 모델 크기 확대 자체가 아니라, **어떤 조건 변화에도 유지되는 구조를 학습하게 하고 그 일반화를 분리 평가하는 것**입니다. 코드 거리, 실행 시간, 장치, 잡음 종류, 논리 회로를 각각 독립적인 평가 축으로 두고, 동일한 평가 데이터에서 신경망과 비신경망 디코더를 비교해야 합니다.

다음으로는 **정확도·지연·불확실성·유지율을 하나의 시스템 지표로 결합**해야 합니다. 디코더가 자신 없는 경우를 표시하고, 그 판단이 실제 실패 확률과 얼마나 맞는지 확인하며, 선별 판단에는 그 시점에 실제로 얻을 수 있는 정보만 사용해야 합니다.

마지막으로, 컬러 코드와 표면 코드를 반드시 하나만 선택해야 하는 대안으로 볼 필요는 없습니다. 대상 논문도 컬러 코드 기반 자원 상태 생성과 표면 코드 계산의 결합 가능성을 언급합니다. **[p.618]** s41586-025-09061-4

**최종 평가:** 이 논문은 **초전도 컬러 코드의 거리 확대와 유용한 논리 연산을 함께 실험한 중요한 연구**입니다. 그러나 가장 강하게 입증한 것은 작은 거리에서의 메모리 오류 억제와 연산 구성요소의 구현이며, **대규모 계산의 총자원 우위, 논리 게이트의 장거리 오류 억제, AI 디코더의 광범위한 일반화는 후속 검증 대상**으로 남아 있습니다.
